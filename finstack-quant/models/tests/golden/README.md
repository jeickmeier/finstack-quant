# Golden fixtures for the models crate

Fixtures live in `data/`. `../vol_models_quantlib_tests.rs` loads the suite
through the shared `golden_path!` macro, which resolves to `tests/golden/<relative>`
in this crate. The generator writes next to itself, so run it from `data/`.

## Suites

### `vol_models_quantlib.json` — 123 cases

Volatility models against QuantLib 1.42.1, generated by `data/gen_vol_golden.py`
(`uv run --with QuantLib --with mpmath python gen_vol_golden.py`). Cases
deserialize as a serde-tagged enum keyed on `model`:

| `model` | Cases | Tolerance | Notes |
|---------|-------|-----------|-------|
| `black76` | 45 | 5e-9 rel | Undiscounted, unit annuity; implied-vol round trip at 1e-8 abs |
| `sabr_lognormal` | 24 | 1e-10 rel | Hagan (2002), beta ∈ {0, 0.5, 1}, plus shifted SABR |
| `heston` | 18 | 1e-6 rel | Gatheral / little-trap formulation, T ∈ {1, 5, 10} |
| `svi` | 12 | 1e-12 rel | Raw SVI total variance; mpmath 50-digit reference |
| `bachelier` | 8 | 5e-9 rel | Includes negative forwards and strikes; round trip at 1e-8 abs |
| `bsm` | 6 | 5e-9 rel | Spot prices with continuous dividend yield |
| `sabr_normal` | 7 | 1e-10 rel | Hagan normal vol; the three beta = 0 cases (one cross-zero) use the exact B.70a form via mpmath, not QuantLib |
| `rough_heston_classical` | 3 | 5e-3 rel | H = 0.499 against classical Heston |

Convention mapping, because a mismatch here looks like a pricing bug:

- Black-76 and Bachelier expected prices are **undiscounted** — QuantLib
  `blackFormula` was called with `discount = 1.0`, matching the unit-annuity
  convention of `black_call`/`bachelier_call`. The discount factor `exp(-rT)` is
  recorded separately in the fixture for provenance only.
- BSM expected prices are discounted spot-based values, computed via
  `blackFormula` on `F = S·exp((r-q)T)` with `discount = exp(-rT)`.
- QuantLib's `sabrVolatility(strike, forward, T, alpha, beta, nu, rho)` swaps
  `(nu, rho)` relative to `SabrParameters::new`.
- Normal SABR at beta = 0 is **not** adjudicated against QuantLib.
  `sabrVolatility(..., Normal)` has no beta = 0 special case and uses
  `zeta = (nu/alpha)·sqrt(FK)·ln(F/K)`; Hagan's exact beta = 0 result (2002,
  eq. B.70a), which `SabrParameters::implied_vol_normal` implements, uses
  `zeta = (nu/alpha)·(F - K)`. The zetas differ by `sinh(L/2)/(L/2)`,
  `L = ln(F/K)` (~0.13% in vol at F/K = 1.5), and only the exact form is defined
  across zero. Those cases are evaluated with mpmath from the exact form (the
  formula of Strata's `SabrHaganNormalVolatilityFormula.volatilityBeta0`); each
  `sabr_normal` case names its source in `reference`.
- SVI has no QuantLib analytic counterpart; it is adjudicated against mpmath at
  50-digit precision.

The 5e-9 closed-form tolerance is not slack. Adjudicated against 50-digit mpmath,
finstack's `norm_cdf` (statrs `erfc`) carries up to ~1e-9 relative price error at
moderate moneyness, while QuantLib's CDF carries up to ~2.5e-9 on far-OTM tail
prices — where finstack is the more accurate side.

Every case variant accepts an optional `skip: bool` (`#[serde(default)]`, so
absent means `false`) as an escape hatch for a known-divergent case that is worth
pinning but not worth failing on. Four Heston T=1 high-vol-of-vol cases carry the
flag explicitly; all four are currently `skip: false` and pass at the 1e-6
tolerance.

References: QuantLib 1.42.1; Hagan et al. (2002) "Managing Smile Risk";
Albrecher et al. (2007) "The little Heston trap"; Gatheral (2004); El Euch &
Rosenbaum (2019).
