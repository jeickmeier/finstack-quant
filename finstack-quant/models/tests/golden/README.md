# Golden fixtures for the models crate

Fixtures live in `data/`. `../vol_models_quantlib_tests.rs` and
`../merton_reference_tests.rs` load their suites through the shared
`golden_path!` macro, which resolves to `tests/golden/<relative>` in this crate.
Each generator writes next to itself, so run it from `data/`.

## Suites

### `vol_models_quantlib.json` — 123 cases

Volatility models against QuantLib 1.42.1, generated by `data/gen_vol_golden.py`
(`uv run --with QuantLib --with mpmath python gen_vol_golden.py`). Cases
deserialize as a serde-tagged enum keyed on `model`:

| `model` | Cases | Tolerance | Notes |
|---------|-------|-----------|-------|
| `black76` | 45 | 5e-9 rel | Undiscounted, unit annuity; implied-vol round trip at 1e-8 abs |
| `sabr_lognormal` | 24 | 1e-10 rel | Hagan (2002), beta ∈ {0, 0.5, 1}, plus shifted SABR |
| `heston` | 18 | 1e-6 rel | Gatheral / little-trap formulation, T ∈ {1, 5, 10} |
| `svi` | 12 | 1e-12 rel | Raw SVI total variance; mpmath 50-digit reference |
| `bachelier` | 8 | 5e-9 rel | Includes negative forwards and strikes; round trip at 1e-8 abs |
| `bsm` | 6 | 5e-9 rel | Spot prices with continuous dividend yield |
| `sabr_normal` | 7 | 1e-10 rel | Hagan normal vol; the three beta = 0 cases (one cross-zero) use the exact B.70a form via mpmath, not QuantLib |
| `rough_heston_classical` | 3 | 5e-3 rel | H = 0.499 against classical Heston |

Convention mapping, because a mismatch here looks like a pricing bug:

- Black-76 and Bachelier expected prices are **undiscounted** — QuantLib
  `blackFormula` was called with `discount = 1.0`, matching the unit-annuity
  convention of `black_call`/`bachelier_call`. The discount factor `exp(-rT)` is
  recorded separately in the fixture for provenance only.
- BSM expected prices are discounted spot-based values, computed via
  `blackFormula` on `F = S·exp((r-q)T)` with `discount = exp(-rT)`.
- QuantLib's `sabrVolatility(strike, forward, T, alpha, beta, nu, rho)` swaps
  `(nu, rho)` relative to `SabrParameters::new`.
- Normal SABR at beta = 0 is **not** adjudicated against QuantLib.
  `sabrVolatility(..., Normal)` has no beta = 0 special case and uses
  `zeta = (nu/alpha)·sqrt(FK)·ln(F/K)`; Hagan's exact beta = 0 result (2002,
  eq. B.70a), which `SabrParameters::implied_vol_normal` implements, uses
  `zeta = (nu/alpha)·(F - K)`. The zetas differ by `sinh(L/2)/(L/2)`,
  `L = ln(F/K)` (~0.13% in vol at F/K = 1.5), and only the exact form is defined
  across zero. Those cases are evaluated with mpmath from the exact form (the
  formula of Strata's `SabrHaganNormalVolatilityFormula.volatilityBeta0`); each
  `sabr_normal` case names its source in `reference`.
- SVI has no QuantLib analytic counterpart; it is adjudicated against mpmath at
  50-digit precision.

The 5e-9 closed-form tolerance is not slack. Adjudicated against 50-digit mpmath,
finstack's `norm_cdf` (statrs `erfc`) carries up to ~1e-9 relative price error at
moderate moneyness, while QuantLib's CDF carries up to ~2.5e-9 on far-OTM tail
prices — where finstack is the more accurate side.

Every case variant accepts an optional `skip: bool` (`#[serde(default)]`, so
absent means `false`) as an escape hatch for a known-divergent case that is worth
pinning but not worth failing on. Four Heston T=1 high-vol-of-vol cases carry the
flag explicitly; all four are currently `skip: false` and pass at the 1e-6
tolerance.

References: QuantLib 1.42.1; Hagan et al. (2002) "Managing Smile Risk";
Albrecher et al. (2007) "The little Heston trap"; Gatheral (2004); El Euch &
Rosenbaum (2019).

### `merton_reference.json` — 61 cases

Merton structural credit and jump-diffusion models against published examples
and QuantLib 1.43, generated by `data/gen_merton_golden.py`
(`uv run --no-project --with QuantLib==1.43 python gen_merton_golden.py`). The generator never
calls this crate: each expected value is transcribed from its source or computed
by an independent implementation. Cases deserialize as a serde-tagged enum keyed
on `model`, and each names its source in `reference`:

| `model` | Cases | Tolerance | Source |
|---------|-------|-----------|--------|
| `kmv_published` | 5 | 5e-5 abs (asset value 500 abs) | MATLAB `mertonmodel` documentation example, printed values |
| `equity_inversion` | 4 | 1e-6 rel | Hull (2022) Example 24.3 plus payout and 5-year cases; independent Newton solve |
| `black_cox` | 8 | 5e-9 abs | QuantLib `AnalyticBinaryBarrierEngine` |
| `jump_bates_limit` | 9 | 1e-7 rel | QuantLib `BatesEngine`, vol-of-vol 1e-4 |
| `jump_quantlib_table` | 27 | 1e-2 abs | QuantLib `test-suite/jumpdiffusion.cpp` table, transcribed |
| `jump_series` | 8 | 1e-6 abs | Merton (1976) Poisson series, independent implementation |

Convention mapping:

- `kmv_published` treats MATLAB's `Liability` as the debt barrier and its
  `Drift` as the physical asset return, so distance to default and default
  probability are the physical-measure ones. Tolerances are half a unit of the
  last printed digit.
- `equity_inversion` reports the risk-neutral `d2`, `N(-d2)` and the endogenous
  debt spread. The Hull case is checked at generation time against an
  independent R replication of the textbook example; the book's own printed
  figures were not available to transcribe. The three payout and multi-year
  cases use the payout convention this crate documents (`e^{-qT}` on assets),
  so they pin solver accuracy; only the zero-payout cases are externally
  anchored.
- No case has a valuation date: every input is a year fraction. QuantLib's
  evaluation date (2026-01-15, recorded in the fixture) only anchors its flat
  term structures.
- QuantLib has no structural credit model. `black_cox` prices a down-and-in
  cash-or-nothing call plus put paid at expiry and divides by the discount
  factor, which is the risk-neutral hitting probability. A barrier growing at
  `g` is a flat barrier under dividend yield `payout_rate + g`.
- The installed QuantLib Python wheel does not export `JumpDiffusionEngine`.
  `jump_bates_limit` uses the near-degenerate Bates setup of QuantLib's own
  `testAnalyticAndMcVsJumpDiffusion`, and the generator asserts it against the
  Poisson series at QuantLib's 2e-8 relative tolerance.
- `jump_quantlib_table` holds QuantLib's recomputed values, not Haug's printed
  ones, which QuantLib notes are not converged. Haug's total volatility and jump
  share are stored already mapped to `sigma`, `mu_jump` and `sigma_jump`. The
  generator asserts every transcribed row against the series at 1e-2.

Not covered by an external reference: the Merton Monte Carlo bond pricer,
`from_cds_spread`, `cds_par_spread`, `to_hazard_curve` and `merton_report`.

References: MathWorks `mertonmodel`; Hull (2022); QuantLib 1.43; Black & Cox
(1976); Merton (1974, 1976); Haug (1998).
