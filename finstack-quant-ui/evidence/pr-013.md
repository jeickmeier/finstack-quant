# PR-013 — supplied valuation summary and measures

`valuation-summary` displays supplied money using its returned rounding stamp,
with instrument ID, as-of date and explicitly labeled numeric, rounding, FX,
version, timestamp and parallel stamps. Missing/partial metadata is unavailable,
not a request to infer defaults. Compact and independent side-by-side views retain
each result's currency and policy context.

`measures-grid` uses the PR-008 unlinked table and native
`listStandardMetricsGrouped` output. Qualified metric keys stay intact; their
canonical family prefix is used only for native group membership. Unknown or
ambiguous group membership is shown as unavailable. All measures remain raw;
optional unit labels require an explicit source and are supplied separately for
each result. Missing comparison measures stay absent rather than becoming zero.
No difference, ratio, aggregate, FX conversion or inferred financial label is added.

The retained `src/fixtures/results/bond.json` is generated by
`tests/results/generate.mjs` through the real Node facade. It includes the complete
request, result, native groups and package WASM SHA-256. A focused test reruns that
request and compares all fields except the inherently changing wall-clock timestamp;
the stored timestamp itself is displayed unchanged. Comparison test values are
explicitly supplied presentation fixtures, not assertions of economic equivalence.

Scoped review passed after correcting the standalone heading level and making
missing nested rounding metadata safe. `mise run ui-check`, `mise run ui-build`,
and `test:results:browser` pass. The five result tests cover direct native fixture
agreement, exact values/stamps/qualified IDs, independent comparison contexts,
missing metadata/value/error/loading states, and explicit unit/group behavior.
The installed browser checks pass axe in both themes and densities, retain right
alignment/tabular numerals, and measure 28/36 px compact/comfortable rows. It loads
no WASM, chart or form runtime. The screenshot was visually inspected.

No full-library suites ran. Rich model details and cashflow presentation remain
owned by their later planned slices.
