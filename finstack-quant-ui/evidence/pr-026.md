# PR-026 — all-instrument workbench composition

The workbench now composes InstrumentForm, MarketContextForm, CashflowViewer and
ValuationDetails with existing pricing/validation hooks. Initial type comes from
the request's discriminator or an explicit host deep-link example. Selecting an
example preserves explicit market and pricing parameters; unsupported combinations
remain native errors. No model, forward, financial quantity or missing result is
inferred. Market changes enter pricing only after native canonical validation.

The market View/Edit modes retain form state. Stored curve points use FinstackTable,
CurveChart and useLinkedSelection with explicit curve/type/coordinate keys and
native cell addresses. Block-owned code is limited to layout, accepted state,
column/channel mappings and callback wiring. Result details retain the completed
request, metadata and exact host values. Cashflows are requested only when opened;
unsupported native exports leave successful pricing and selected model untouched.

Docs use a host-owned query parameter and Suspense boundary to open canonical
examples. Generated consumer hooks remain ignored and are installed from registry
owners. Scoped registry docs export runs without notebooks or unrelated site routes.

Focused senior review: PASS. Complete requests reach shared hooks, native validation
owns market acceptance, typed/raw detail routing and exports stay with their
standalone owners, and no private block field renderer or calculation was added.
Compound native integration tests have explicit timeouts that accommodate their
multi-step work; there is no change to runtime timing or numerical tolerances.

Validation: ui-check (491 tests), ui-build, ui-docs-check, ui-docs-build and 54
relevant facade regressions pass. Installed and served workbench smoke checks
compare actual edited requests/results with the direct facade. The Phase 2
installed consumer covers all five detail variants plus wide-seed bond diagnostics,
exact FX/cross-currency swap exports, native unsupported equity-option export,
market editing and bidirectional stored-node selection; accessibility is clean.
All 78 served catalogue links open their exact canonical example IDs with no page
errors. Existing full-inventory renderer/edit/validation/pricing matrices retain
all positive cases. The served artifact retains the pinned WASM digest and revised
25,000,000-byte gate. No full-library, notebook or aggregate docs-site build ran.

This closes the scoped component/workbench acceptance for Tasks 2.5 and 2.6 and
Phase 2's registry gates. Aggregate library/site, release and cross-platform gates
remain outside this evidence, rather than being certified by scoped docs export.
