# PR-039 — Registry metadata and distribution

## Implemented

All 150 items carry generated registry/WASM versions, canonical schema IDs and
one of the three visual categories where applicable. IDs come from the existing
contract/provenance inventory and each installed dependency closure. Pure
presentation items have no schema IDs. Generation and registry checks reject
drift; the worker warns once per mismatched returned valuation version without
changing the result.

The docs build installs and serves the registry at `/r/`. A separate registry-only
publication workflow verifies the registry, builds at `/finstack-quant`, publishes
GitHub Pages and exercises CLI/MCP from an empty Ubuntu consumer. The public check
compares the index and every served item's complete source against the exact Pages
artifact before testing discovery. Native WASM npm publication remains excluded;
installation instructions retain the matching local package workflow.

Hosted registry tests use two workers to reduce the concurrent WASM/schema load
seen in the earlier PR-037 CI timeouts. Assertions and deadlines are unchanged.
This has been validated locally with `CI=1`; hosted CI is not yet claimed green.
