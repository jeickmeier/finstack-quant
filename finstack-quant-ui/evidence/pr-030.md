# PR-030 — native volatility cube explorer

sampleCube forwards complete canonical cube state into core.VolCube. It flattens
nodes in the published alpha/beta/rho/nu/shift order, turns an absent shift into NaN
only at that constructor boundary, preserves forwards and interpolation_mode, and
calls the explicitly selected checked normal or Black/lognormal evaluator. Handles
are freed on successful and failed evaluations. No clamped API, SABR formula or
forward-offset conversion is used in TypeScript.

useCubeSamples snapshots every canonical field, coordinate, absolute strike and
convention in its session query identity, retaining distinct non-finite invalid
requests. VolCubeExplorer provides an explicit absolute-strike input and output
convention control. It uses the existing shared surface grid/table/slice/selection
and figure export presentation, while raw parameters, forwards, optional shifts
and complete canonical JSON remain separately visible. Color extents are explicit
for each evaluator's different output units. Generated market editors now support
cube parameters and forwards through native validateMarket, with per-cube deferred
controls and complete retained form state.

The normal fixture is the actual native output of 07_swaption_vol_surface.json,
with its source SHA recorded and freshness tested by a fresh calibration. A shifted
fixture with a negative forward is separately native-validated. Real Comlink worker
tests cover both evaluators, every SABR parameter, forward and coordinate changes,
interpolation/query identity, absent/present shifts at the constructor boundary,
checked out-of-grid and invalid-model errors, and matching allocation/free counts.

Scoped senior review: PASS. Explorer tests assert raw table/JSON identity, explicit
strike/convention requests and no sampling of incomplete decimal text. Generated
editor tests compare the complete accepted market after alpha/forward changes and
reject invalid alpha. The installed browser compares every displayed value with the
direct native facade for both conventions, a changed strike, edited parameters and
forwards, and shifted-cube switching. It verifies the caller tooltip, exported
convention labels/prose/sources, exact native checked-error message, one shared WASM
load, and zero page/accessibility failures in light and dark themes. Screenshots
were visually inspected.

Validation: ui-check (515 tests), ui-build, focused real-worker/query/explorer/editor
checks, and the installed cube browser. No full-library/notebook suite or new WASM
build ran. This closes Task 3.2 within the component registry scope and preserves
all deferred contracts.
