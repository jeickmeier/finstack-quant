# PR-036 — Served gallery and accessibility

Status: local gallery verification passed; remote CI gate is not yet closed.

The production docs export now includes `/registry-gallery/`. Its inventory is
projected from the complete registry: 48 visual items (including the theme) and
102 nonvisual items. The pinned installer installs all 150 into the docs consumer.
Each visual harness calls its installed owner. Nonvisual harnesses import installed
targets without initializing WASM; worker execution is exercised by native forms
and market views. This shared consumer is not the independent-install matrix.

The gallery retains source hashes for native fixtures. Cases include raw
mixed-currency cashflows, a losslessly decoded Monte Carlo seed above 2^53,
normal/shifted cubes, stored surfaces, FX sampling and native calibration residuals.
The supplied trace and other illustrative data are explicitly labeled.

`ui-e2e` serves the production static export. The 199 tests cover 192 item/state
screenshots, two publication widths, shifted cube, nonvisual imports, accepted
row/cell/chart selection, custom tooltip keyboard actions, and bond-form keyboard
traversal/submission/popover dismissal. Serious/critical axe violations fail before
a baseline is written. UTC, en-US, 1x scale and pinned Chromium are explicit;
only volatile calculation timestamps are masked. Verification defaults to no
snapshot updates. Baselines are macOS-specific evidence.

Initial baseline capture deliberately uses `mise run ui-e2e -- --update-snapshots`.
Representative runs preceded the full capture. Review corrected the test's wrapped
SVG text assertion, reused the existing interactive chart example for tooltip
checks, excluded controls inside closed disclosures from the visible keyboard walk,
corrected the calendar selector to its field-specific accessible name,
and fixed the gallery's preview scroll accessibility and two-pixel width mismatch.
The affected initial baselines were explicitly regenerated after rebuilding.

The dedicated CI job builds only native packages required by the registry, checks
the registry, exports scoped docs and runs the gallery suite. It uses Rust 1.91.1,
wasm-pack 0.14.0, Binaryen 130, Node 24.16.0 and uv 0.10.11, matching the verified
registry toolchain rather than installing the broad workspace tool set. Binary
release downloads have verified SHA-256 digests. The macOS 15 ARM runner and
matching ARM release assets follow the [current GitHub runner matrix](https://docs.github.com/en/actions/reference/runners/github-hosted-runners). The existing Documentation
workflow accepts a `registry_only` dispatch that skips its Rust/host docs jobs.

No full-library, notebook or aggregate-site test/review suites are part of this PR.

Local production verification: 199/199 tests passed in 201.5 seconds, with no
skips, retries, unexpected results or page errors. All 192 standard states have
zero serious/critical axe violations. All 195 captured PNGs were visually reviewed
in contact sheets; the narrow publication figure was also inspected at full size.
The no-update run verified their pixels. Snapshot dimensions and SHA-256 values
are retained in `pr-036-gallery.json`.

Scoped senior review: no remaining source-code blockers. The gallery uses installed
component owners, retains native/wire data boundaries, derives complete inventory
coverage, and adds no parallel financial renderer. The only runtime presentation
fix in this slice is the gallery's keyboard-accessible preview container. Snapshot
updates are explicit; independent installs and desktop publishing remain separate.

The final `mise run ui-check` passed all generation, format, token/contrast,
installed-import, TypeScript and 555 unit checks across 42 files (85.9 seconds).
The scoped production docs build passed before browser verification. No broad
pre-commit hooks or full-library suites were run.
