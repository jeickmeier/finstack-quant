# PR-010 — complete publication figures

`finstack-chart` pins TanStack Charts 0.18.0 and accepts its typed definition:
native scales, axes/tick policies, legends and annotation marks. A shared
composition adds title, subtitle, caption, ordered source labels/URLs and
figure-relative notes. Native runtime/guide layout reserves plot geometry;
only publication prose wrapping and its reserved bands are added here.
No WASM, table, form or pricing runtime enters the installed closure.

The public ChartTextMeasurer contract accepts a browser glyph-metrics adapter.
The package's createDomTextMeasurer implementation is private (not exported by
its package map), so this small adapter supplies the same browser measurement
to prose and native guides. It does not replace scales, tick generation, mark
rendering or typography with a second chart grammar.

Screen and export use the same responsive native definition and SVG renderer.
Export waits for fonts, recompiles at the requested dimensions, adds the same
persistent prose through native SceneLabel nodes, embeds matching readable
FontFace rules, and uses native serializeChartSvg/renderChartImage. SVG retains
editable text and vector marks with resolved styles; PNG dimensions are explicit.
The standalone installable example exports a 900×600 vector figure and 1800×1200
PNG (6×4 inches at 300 PPI). Fontsource fonts carry their existing SIL OFL license;
desktop applications that ignore embedded webfonts require IBM Plex Sans installed.

Scoped review: PASS. Visual inspection found that native legend placement is
relative to the SVG boundary, so its documented render/control context now shifts
into the reserved plot area. The native responsive runtime lets outer options
override returned specs; static spec fields are removed from those options so
original scales/color cannot undo figure layout. Regression checks catch prose
versus chart-label overlap, and notes have explicit theme spacing from axes.
The example's supplied callout placement was adjusted to stay clear of its line.

Validation: `mise run ui-check` (237 tests), `mise run ui-build`, and
`test:figures:browser`. Six exports cover numeric/date/category axes, negative
scientific ticks, native point/text/arrow/reference/range annotations, relative
figure notes, long headings, captions and multiple sources at 340/900 px widths.
Browser geometry checks found no clipped text or prose/chart-label overlap;
SVG text/vector/style/font checks and PNG pixel dimensions passed. Axe passes
in light/dark and compact/comfortable, and light export from a dark app passes.
The inspected `/tmp/pr010-numeric-{340,900}.png` exports and gallery screenshot
are reproducible with the retained harness. Desktop-editor verification remains
PR-038; interaction APIs are PR-011 and canonical curve views PR-014.
