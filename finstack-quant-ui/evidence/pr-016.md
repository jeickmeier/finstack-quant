# PR-016 — embeddable bond workbench

`PricingWorkbench` composes the accepted instrument/pricing forms, stored curve
chart, measures grid (including its valuation summary) and shared JSON viewer.
Base UI tabs retain mounted form state. The host supplies the route and shared
Finstack/Query provider boundary. Initial request data is snapshotted; complete
requests debounce for 250 ms after current inputs validate. Unsupported types and
invalid market/JSON inputs cannot submit a price. Results remain paired with their
last completed request while edits or a newer pricing failure are visible.

Before block implementation, worker/hook/example targets were corrected to follow
the consumer source directory. The pinned CLI target resolver adds `src/` to
ordinary targets for src-layout applications; the previous `~/` targets forced
these files outside that alias. All relative worker imports now remain colocated.
Fresh CLI-built corpus extraction type-checks in both root and src layouts. The
focused existing worker tests passed before block changes began. This is target
and import evidence; PR-017 still owns actual external Next installation.

Scoped senior review: PASS after fixing request preview serialization when optional
fields are undefined. PriceRequest consists of strings and string arrays, so JSON
preview serialization omits undefined properties without parsing embedded wire JSON.
Returned structured results still use the lossless host codec. No block-private
schema definitions, controls, figures, tables, raw viewers or financial calculations
were introduced; the shared generated market codec rejects calibration envelopes.

Validation: `mise run ui-check` (267 tests), `mise run ui-build`, three composition
tests and an additional installed Vite/Chromium smoke pass. Composition tests use
a controlled worker client and native Node operations, with only the chart host
stubbed because jsdom lacks Canvas/ResizeObserver. Chromium renders the real charts
and worker, edits the bond, compares every returned field with the direct facade
apart from timestamp, verifies tab/state/result persistence, and passes axe. The
screenshot was inspected. No full-library suites ran.

PR-015 and this slice close Task 1.9. PR-017 retains the production Next/static
exports, optimized package and clean external installation gates.
