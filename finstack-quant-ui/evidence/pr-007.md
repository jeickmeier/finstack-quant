# PR-007 — lossless display formatting

`finstack-format` provides exact decimal grouping, source-backed reversible rate
presentation, native ISO/epoch-day adapters and Table v9 column presets. The
separate transport entry re-exports the existing codec/host adapters; importing
a scalar formatter does not initialize the valuation validator or WASM.

Money formatting reads the supplied currency's returned output scale and mode.
Missing scale metadata preserves the original amount digits. Big.js 7.0.1 performs
presentation rounding according to `core::config::RoundingMode` and
`core/src/money/rounding.rs`; it never replaces the canonical amount. Generic
numeric values keep raw text and unavailable units. Rate units require an
explicit source reference, using the published core.Rate decimal/percent/bp
convention; no field/metric name classification is added.

Date conversion calls `core.createDate`/`dateFromEpochDays`; the adapter only
parses/renders date components and guards integer coercion. Browser date calls
belong inside the worker. Money columns retain per-row currencies, and signed
columns only format supplied values. Table 9.2.4 types verify the core-only
presets; no selection, aggregation or sorting behavior is added.

Scoped review: PASS. Covered 20-digit values, fractional scaling, small numeric
rates, every returned rounding mode including negative ties, currency-specific
scales, missing metadata, negative zero text, invalid dates and epoch overflow.
Separated transport exports during review to avoid eager schema loading.

Validation: `mise run ui-check` (185 tests), `mise run ui-build`, and the focused
formatter/host/installed-registry checks after separating transport. The actual
WASM harness now imports transport through this registry entry and still proves
wide seeds and u64::MAX export as unquoted integer tokens accepted by Rust;
quoted seeds are rejected. Exact decimal money survives native construction.
No full library suites or new financial calculations were introduced.
