# PR-028 — stored volatility surfaces

vol-surface-chart composes the shared native heatmap preset, FinstackTable,
useLinkedSelection and native point slices. The adapter reads expiries, strikes and
vols_row_major exactly, retains source references, checks row-major dimensions and
uses explicit coordinate keys. secondary_axis and quote_type own labels; the caller
supplies a color extent in raw units. There is no plain-surface evaluation or local
interpolation. Caller tooltip notifications, publication prose, annotation text and
shared export handles are forwarded. Changed source data remounts native figures so
pinned tooltips cannot retain removed or changed nodes. Removed selection keys have
no active representation; the external parent remains the sole state owner.

fx-delta-quotes shows canonical ATM/RR/BF arrays and complete original JSON separately
from stored volatility grids. Missing optional wings remain unavailable. It requires
no worker and performs no forward or delta conversion.

MarketContextForm now exposes generated surface and FX quote editors through its
existing native validateMarket path. Each surface editor expands independently;
closed controls retain complete form state and still undergo native validation.
This avoids mounting hundreds of inputs for a populated desk market. SchemaForm's
presentation callback can delegate to the generated renderer; a focused regression
covers optional-field delegation without recursively reapplying the override.

volatility. Existing populated-market preservation coverage retains all 20 surfaces.
