# PR-029 — native FX delta-surface evaluation

sampleFxDelta constructs the published core.FxDeltaVolSurface from every canonical
quote array, evaluates each original expiry/strike/forward through the checked
models.volatility.getFxDeltaVol facade and frees the handle in finally. Optional
absent wings become undefined only at the constructor boundary. There is no local
forward formula, curve selection, delta conversion or interpolation.

useFxDeltaSamples snapshots complete input state, keys all quotes/coordinates and
forwards plus the worker session, and disables null requests. Non-finite numeric
inputs have distinct key encodings instead of collapsing to JSON null; they still
reach native validation unchanged. Structured errors retain the shared envelope.

FxSurfaceChart keeps raw ATM/RR/BF quotes visible and requires an explicit forward
for every coordinate before sampling. Evaluated annualized Black/lognormal decimal
volatility uses the same surface presentation as stored grids. The shared view was
extracted from PR-028 without introducing another selection/export mechanism or
pretending evaluated values are a canonical stored surface. Original coordinate
references and explicit coordinate keys reach caller tooltips and notifications.
Quote editing uses the generated MarketContextForm and native validateMarket path.

Scoped senior review: PASS. Real Comlink worker tests compare direct facade results
after all quote-axis/ATM/RR/BF and coordinate/forward changes, including 10-delta
wings. They verify immutable requests, query invalidation, native constructor and
evaluator errors, and matching constructed/freed handle counts after failures.
Component tests verify missing forwards make no call and native failures replace
successful evaluated views without hiding raw quotes.

The installed browser consumer compares every displayed sample with direct native
results before/after forward and canonical ATM quote edits. It verifies both table
and keyboard activation, original coordinate keys, caller tooltip exclusion from
export, explicit provenance/caption/source text, missing-forward gating after a
failure, one shared WASM load, and clean light/dark accessibility. Screenshots were
visually inspected. The PR-028 installed stored-surface suite also passes after the
shared-view extraction, including clears, removed nodes, exports and large grids.

Validation: ui-check (509 tests), ui-build, installed FX and stored-surface browser
checks. No full-library/notebook suite or new WASM build was required. Together with
PR-027/028 this closes Task 3.1's registry scope. Full-state curve evaluation and
plain-surface off-grid evaluation remain excluded.
