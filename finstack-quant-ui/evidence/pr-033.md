# PR-033 — native reports and residual figures

CalibrationReport accepts the published CalibrationReport contract and presents
returned status, convergence, raw residuals, optional diagnostics and complete JSON.
Plan-level ratio fields stay distinct from raw metrics. Native target/fitted fields
are labeled as solver representations; zero target and fitted equal to residual do
not imply observed/repriced quotes. Structured failures retain all supplied fields
and distinguish missing solver diagnostics. No report metrics are recalculated.

CalibrationFitChart plots the signed residual map against a decorative zero rule.
Each step and canonical input quote kind/type has separate native scales; unmatched
quote IDs get individual panels, never a guessed shared financial scale. Missing
quote-unit metadata is explicitly labeled solver units. Every callback datum retains
its original report and input quote references. Shared accepted selection links the
report table and chart; the existing figure wrapper supplies tooltips, callbacks,
annotations, SVG/PNG handles and complete publication text. Data changes remount
native figures to discard stale transient tooltip data. Raw figures need no worker.

Scoped senior review: PASS for the registry projection. Fixtures record all 12
source envelopes/hashes and native results, plus a native diagnostics-enabled case
and an actual solver failure. Five focused checks verify inventory coverage,
every returned signed residual and original step/quote identity, native zero domain,
deposit/swap separation, missing-identity isolation, exact plan/step/diagnostic JSON,
zero-target diagnostics and structured failure data. The installed PR-032 consumer
also exercises linked table/chart activation with original report callbacks, custom
tooltips, and complete SVG labels, caption, source and annotation with transient
tooltips excluded. Native calibration/edit/diagnostics/failure/pricing checks remain
in that consumer. Both themes pass axe with one shared worker WASM load and no
main-thread WASM import. Screenshots were visually reviewed.
