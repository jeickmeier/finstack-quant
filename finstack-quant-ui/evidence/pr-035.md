# PR-035 — market and calibration workbench composition

The workbench composes the complete market browser/editor, stored-curve table/chart,
stored surfaces, explicitly configured native cube/FX evaluators, calibration form,
static diagnostics, native report/residual views and optional structured-credit
scenario detail. Blocks own layout, request state, selection and callback wiring;
all financial computation and domain rendering remain in their existing owners.

StoredCurveView extracts the existing stored-node table/chart composition into the
curve component. The browser now supplies that view for selected curves. Stable
identity follows curve ID/type rather than assuming canonical array order. Complete
raw market, calibration, valuation and scenario JSON remain available.

SchemaForm's optional onInputJson exposes structurally valid working JSON before
native validation, and clears it immediately on edits. Calibration dry-run can thus
show semantic dependency errors while native validation still gates submission.
The Calibrate tab accepts complete envelopes; no solver or quote defaults are
invented. Plan and step reports remain separate. Residual panels share accepted
selection with their report and forward existing figure options/export refs.

Use calibrated market validates final_market through the existing market hook,
checks that the solved request still matches current accepted input, and remounts
the editor with that exact canonical snapshot. Pricing consumes the same accepted
market. Edits to the calibration envelope disable stale-result handoff. Last
completed valuation/cashflow context remains visible during subsequent failures.

Scenario requests snapshot all five published facade inputs and worker session.
The service delegates directly to structuredCreditTrancheScenarioTable; the block
opens this existing heatmap only for an explicitly configured, completed
structured-credit request. No pricing units, balance normalization or missing
scenario inputs are inferred.

The docs and installed demo supply explicitly documented illustrative evaluation
inputs. Production callers own strike, forwards, coordinates and display extents.
The library defaults to stored views when those inputs are absent.

Scoped senior review: PASS. Block imports and dependency closures use component
owners, complete native request identity and structured error paths. There is no
copied financial calculation or private field/chart renderer. Tests cover native
scenario identity/failures and immutable queries, structural-versus-native
calibration acceptance, immediate invalidation and a late market-validation race.

The isolated race test rejects late validation after an input change. The served
