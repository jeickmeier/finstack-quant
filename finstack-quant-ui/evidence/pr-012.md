# PR-012 — schema-driven bond form

`finstack-form` pins TanStack Form 1.33.5 and registers shared contexts, text,
decimal/date/enum/boolean fields, fieldsets, array controls, error summary and
submit/reset controls. It is a visual `registry:ui` item installed at
`lib/finstack/form.tsx`, so the registry's existing tier rules continue to enforce
its dependency on primitives. `schema-form` is a component above that field kit.

The generated module's canonical schema and metadata supply presentation shape,
references, descriptions, enum branches and defaults. The generated codec's public
Zod validator is a transform and cannot be walked as a field tree; the renderer
therefore reads the associated generated schema, while the codec remains the only
structural validator. TanStack Form runs that validator on changes and invokes the
abort-aware native validator after 250 ms. `useInstrumentValidator` connects this
callback to the actual PR-009 worker and retries validation when worker readiness
or reset changes its identity. Canonical native output is emitted only on submit;
it is never assigned back to active edits.

Working numeric text is converted only for validation/output. Exact decimal text
stays text, int64/uint64 text becomes bigint, and the existing generated codec
checks ranges and emits numeric tokens. Scalar schema examples are not defaults:
newly enabled IDs stay empty unless a default is declared. New branch fields also use declared defaults only; the module example initializes
the complete starting instrument. Basic layout discloses defaulted fields
under More; field allow/deny filters retain hidden values. Arrays add/remove/move
through TanStack Form. Nullable references and external/internal/adjacent tags
preserve their canonical shape, including mixed unit/data-bearing variants.

Scoped review: passed after fixing unsafe scalar example defaults, mixed enum
branch omission, and primitive-to-object coercion. Visual review also caught recursively narrowing
grids; object groups now span the form, redundant envelope frames are removed,
and the installed browser asserts usable nested field widths. Generic object shapes cannot
silently turn invalid primitive input into an empty object. Native validation
errors without a mapped field path appear in the summary; complete cross-instrument
path mapping and renderer coverage remain PR-019/PR-021.

Validation: `mise run ui-check`, `mise run ui-build`, and the retained
`test:form:browser` installed-consumer harness. Nine focused form tests cover the
real generated bond, decimal errors, native Node canonical validation, preserved
working values, nullable IDs, stale async rejection, array controls and hidden
values, exact native uint64 tokens/range boundaries, and discriminator encodings.
The browser lazily imports the bond module, initializes the actual shared WASM
worker, edits/submits fields and verifies canonical output, preserves `001` working
text after native integer canonicalization, and passes axe. No table/chart runtime
appears in the main bundle. This fixture uses the ordinary release WASM artifact;
it is not a new measurement of the separately optimized 25 MB size gate.

No full-library suites ran. General renderer coverage remains explicitly gated;
passing this bond subset does not certify every instrument or schema construct.
The Merton seed transport fixture uses the reference model inputs from
`finstack-quant/valuations/benches/merton_mc_pricing.rs`; no pricing or economic
model test is run by this form slice.

Primary library guidance: [TanStack Form composition](https://tanstack.com/form/latest/docs/framework/react/guides/form-composition)
and installed 1.33.5 form validation/types.
