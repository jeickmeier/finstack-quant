# PR-008 — controlled primitives

Eighteen public controlled inputs/displays plus a shared field frame install with
explicit dependencies. Base UI owns controls/focus, DayPicker owns the calendar
presentation, and TanStack Table 9 runs with empty features and supplied row IDs.
The ID autocomplete virtualizes caller-supplied suggestions. Canonical decimal,
tenor, day-count and BDC contracts are generated from their source schemas.

Review: PASS. No financial rules, local market option catalogue, sorting or
aggregation were introduced. Decimal text remains exact; numeric representations
retain invalid editing text rather than coercing hexadecimal or whitespace.
Currency changes preserve amount digits. Raw JSON copy preserves original bytes.
Review also corrected a JSX-escaped integer pattern and callback argument leaks.

Validation: `mise run ui-check` (223 tests), `mise run ui-build`, and the production
`test:primitives:browser` consumer. All public primitives have DOM axe checks;
real Chromium axe includes contrast in all four theme/density combinations.
Installed sources type-check against the consumer's own alias and build with
Vite. Keyboard tests cover help Escape/focus, radio/select, calendar, free-text ID
and virtualized navigation to the last of 10,000 suggestions. Clipboard text is
exact and the consumer makes no WASM requests. The inspected dark screenshot is
retained by the harness at `/tmp/pr008-primitives.png`.

The browser's initial contrast failure was a fixture omission: its Tailwind
sources excluded the HTML body carrying `finstack-surface`. The corrected fixture
includes that source; no contrast checks were waived. Home/End correctly retain
native text-editing semantics; ArrowUp selects the last suggestion.

Package dependencies come from the locked installation. This does not claim the
later fresh network installation matrix, full form support, or library-wide
validation. No Rust/Python/full library suites ran.
