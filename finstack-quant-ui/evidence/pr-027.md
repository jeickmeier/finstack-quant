# PR-027 — shared heatmap preset

The existing finstack-chart item now exports a native cell/text preset. Caller rows,
coordinates, values and stable keys remain intact. Explicit finite color extents
are required; diverging extents include a caller-owned meaningful center. Duplicate
keys/coordinates and extents that hide supplied values are rejected. Native band
scales, quantitative D3 color, axes, legends, tooltip and accepted-selection APIs
own their respective behavior. Decorative text never creates duplicate hit targets.

Definitions can resolve the shared FigurePresentation before constructing a native
chart definition. This is used for CSS-resolved ramps, cell-text colors and size,
including exports with a theme different from the screen. No secondary chart,
scale engine, state synchronization, table or WASM dependency was introduced.

Values print only when both dimensions are at most 12. Review found that the prior
cell-dark token missed 4.5:1 between continuous ramp stops. Its shared theme value
is now black; tests sample 1,001 values across each ramp in each theme. Culori is
promoted from an existing development dependency for contrast selection; D3 and
both declaration packages are included in the installed item dependencies.

checks cover original row/coordinate identity, native point counts, 12/13 boundaries,
invalid identities/extents and contrast. Existing figure composition tests pass.
The installed browser fixture verifies keyboard activation and explicit cell keys,
pinned-tooltip dismissal, caller tooltip exclusion from SVG, light/dark complete
exports with captions, sources and an annotation, unclipped text, no printed values
on 13 x 13, zero accessibility violations and zero WASM requests. Screenshot was
visually inspected. Existing publication and all stored curve browser checks pass.
