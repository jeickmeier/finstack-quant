# PR-022 — exact native cashflow viewer

The individual cashflow-viewer composes use-cashflows and JsonViewer. The query
snapshots instrument JSON, market JSON, as-of, selected model and worker session;
no field is interpreted or defaulted. The former cashflow hook nested inside the
pricing hook is removed. Caller valuation/model state is never changed by export.

Source-pinned fixtures retain exact native strings for the bond, FX swap and
cross-currency swap, including all USD/EUR amounts, PV tokens and metadata. A real
Black76 equity option prices successfully and returns the native unsupported-model
cashflow error. The viewer displays that error with an unavailable label while
leaving valuation and selected model visible. No row schema, totals, normalization
or reconciliation are inferred in the client.

Focused senior review: PASS. Rendering, clipboard and print use the original
string. JsonViewer supports both densities and now breaks long raw tokens on
printed pages without changing the text; visual inspection caught and fixed
horizontal clipping. Loading/error and worker/session query boundaries are tested.
Fixture generation --check confirms source hashes and current native output.

Validation: ui-check (457 tests), ui-build and the standalone installed Chromium
consumer pass. All three positive fixtures copy exactly in both densities, the
unsupported case retains successful pricing, print wraps within page width and
hides controls, and all accessibility checks report zero violations. The browser
loads one shared WASM asset. No full-library or notebook suites ran. Together with
PR-018, this completes Task 2.3; workbench composition remains PR-026.
