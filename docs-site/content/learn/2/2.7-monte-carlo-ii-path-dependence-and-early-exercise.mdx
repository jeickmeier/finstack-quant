### Path dependence begins with the observations

For positive observed prices $S_{t_1},\ldots,S_{t_m}$, define the arithmetic average $A=m^{-1}\sum S_{t_i}$ and geometric average $G=(\prod S_{t_i})^{1/m}$. An Asian call pays $(A-K)^+$ or $(G-K)^+$. Specify whether $t_0$ is included. Since $A\geq G$, the arithmetic call dominates the geometric call on each matched path. It need not dominate a terminal vanilla call path by path.

Under GBM, the geometric average has an analytical distribution, giving the [Kemna–Vorst benchmark](/references.html#kemna-vorst-1990). The arithmetic `asian_option_price` route uses [Turnbull–Wakeman](/references.html#turnbull-wakeman-1991), an approximation. Treating that value as an exact arithmetic benchmark confuses approximation error with sampling noise. With one terminal fixing, both averages become the same terminal price, so both reduce exactly to the corresponding vanilla contract.

A geometric Asian can be a control variate for an arithmetic Asian: subtract a fitted multiple of its simulated deviation from its known expectation. This works because the two payoffs are strongly related. The displayed Python workflow does not expose an automatic injectable control-variate engine; the exact geometric value is used to audit captured-path arithmetic.

### A barrier is an observation rule

An up-and-out call survives only if no monitored price reaches its upper barrier. Adding observations can only remove surviving paths when payoff, rebate and path are held fixed. Thus a coarse discrete knock-out is at least as valuable pathwise as a finer nested one. Continuously monitored survival is more restrictive still.

The [Reiner–Rubinstein](/references.html#reiner-rubinstein-1991) `barrier_call` formula here is continuously monitored and has no monitoring-frequency argument. The discrete sweep must therefore use captured paths. Independently generated coarse and fine simulations obscure the pathwise comparison with sampling noise.

The [Broadie–Glasserman–Kou correction](/references.html#broadie-glasserman-kou-1997) approximates discrete monitoring by shifting a continuous barrier outward by a factor involving $\exp(\beta\sigma\sqrt{\Delta t})$, with $\beta$ about 0.5826: an upper barrier moves up and a lower barrier moves down. It is an approximation under its assumptions, especially delicate near a barrier, with irregular monitoring or additional contractual features. We do not substitute it for the explicit observation experiment.

### Exercise value is a policy problem

At an exercise date, compare immediate exercise with conditional expected continuation value. Least-squares Monte Carlo regresses realized discounted future values on basis functions of the current state, typically using relevant in-the-money paths. Backward induction fits an exercise policy on the chosen grid.

Reusing those paths to value their fitted policy creates training optimism. `price_american_put_unbiased` evaluates that learned policy on independent pricing paths. Its name refers to the policy-evaluation sampling step; the policy can remain suboptimal and the grid finite. The true American put value is at least the corresponding European value because waiting to maturity remains feasible. A finite simulated estimate can lie below it because of sampling or policy error. A finite exercise grid is economically Bermudan. [Glasserman, chapter 8](/references.html#glasserman-2004-monte-carlo) provides the regression and policy-estimation framework.

The wrapper exposes prices, errors and path counts, but no exercise-boundary object. The computed spot-price plot compares held-out policy values with European and intrinsic values. A separate, explicitly illustrative policy schematic explains exercise and continuation regions without claiming to export an engine boundary. The executable path-count study changes training and independent pricing samples while keeping the grid fixed. A small interval around a weak learned policy does not certify an accurate American price.

For a Bermudan swaption, the state process is an interest-rate model and exercise delivers an underlying swap. A Hull–White 1F tree and Hull–White Monte Carlo share model assumptions but use different numerical methods. The fixture specifies mean reversion and volatility directly; it is not a calibrated market cube. [Hull–White](/references.html#hull-white-1990-pricing-ird) and [Brigo–Mercurio](/references.html#brigo-mercurio-2006-interest-rate-models) supply the rates context.

fixings = paths[:, 1:]
arithmetic_payoffs = math.exp(-0.05) * np.maximum(fixings.mean(axis=1) - 100, 0)
geometric_payoffs = math.exp(-0.05) * np.maximum(np.exp(np.log(fixings).mean(axis=1)) - 100, 0)
for convention, payoffs in [("arithmetic", arithmetic_payoffs), ("geometric", geometric_payoffs)]:
    reference = asian_option_price(*args, 12, convention, True)
    standard_error = payoffs.std(ddof=1) / math.sqrt(len(payoffs))
    label = "TW approximation" if convention == "arithmetic" else "exact geometric formula"
    print(f"{convention}: MC={payoffs.mean():.6f}; SE={standard_error:.6f}; "
          f"{label}={reference:.6f}; difference={payoffs.mean()-reference:.6f}")
    if convention == "geometric":
        pass

from finstack_quant.models import barrier_call

fine_paths = np.asarray(simulate_gbm_paths(100, 0.05, 0, 0.20, 1, 252, 4096, seed=17).paths)
terminal_payoffs = math.exp(-0.05) * np.maximum(fine_paths[:, -1] - 100, 0)
continuous = barrier_call(100, 100, 120, 0.05, 0, 0.20, 1, "up", "out")
previous_payoffs = terminal_payoffs
print("observations | sampled up-and-out value | SE | gap to continuous")
for observations in (4, 12, 252):
    observed_spots = fine_paths[:, ::252 // observations]
    payoffs = terminal_payoffs * (observed_spots.max(axis=1) < 120)
    standard_error = payoffs.std(ddof=1) / math.sqrt(len(payoffs))
    print(f"{observations:12d} | {payoffs.mean():.6f} | {standard_error:.6f} | "
          f"{payoffs.mean()-continuous:.6f}")
    previous_payoffs = payoffs
print(f"Continuous-monitoring analytical value: {continuous:.6f}")

<Exercise title="1. A lookback dominates the matched vanilla payoff" question="Price a discretely observed fixed-strike lookback call and its matched terminal vanilla call on exactly the same paths. Prove the inequality before averaging.">

The running maximum includes the terminal observation, so $(\max_j S_{t_j}-K)^+\geq(S_T-K)^+$ on every path. The code proves this identity and independently checks the vanilla leg against Black–Scholes within four SE. It makes no analytical accuracy claim for the discrete lookback price.

lookback_paths = np.asarray(simulate_gbm_paths(100, 0.05, 0, 0.2, 1, 252, 8192, seed=31).paths)
vanilla_path_value = math.exp(-0.05) * np.maximum(lookback_paths[:, -1] - 100, 0)
lookback_path_value = math.exp(-0.05) * np.maximum(lookback_paths.max(axis=1) - 100, 0)
vanilla_exact = bs_price(100, 100, 0.05, 0, 0.2, 1, True)
lookback_se = lookback_path_value.std(ddof=1) / math.sqrt(len(lookback_paths))
vanilla_se = vanilla_path_value.std(ddof=1) / math.sqrt(len(lookback_paths))
print(f"Vanilla exact={vanilla_exact:.6f}; matched MC={vanilla_path_value.mean():.6f}")
print(f"Discrete fixed-strike lookback={lookback_path_value.mean():.6f}; SE={lookback_se:.6f}")
print(f"Matched-path incremental payoff={np.mean(lookback_path_value - vanilla_path_value):.6f}")

<Exercise title="3. What correlation does a quanto need?" question="Sweep equity–FX correlation from -0.5 through zero to +0.5. State the FX quote direction and recover the vanilla limit at zero correlation with equal domestic and foreign rates.">

With FX quoted as domestic currency per unit of foreign currency, foreign-equity volatility $\sigma_S$, FX volatility $\sigma_X$ and correlation $\rho$, the domestic-measure foreign-equity drift is $r_f-q-\rho\sigma_S\sigma_X$. The claim converts at the contractual fixed conversion rate and discounts domestically. Increasing this correlation lowers the call value in the displayed convention. Reversing the FX quote reverses the sign convention; reusing an unlabelled correlation number is unsafe.

{/* notebook-block notebook="07_advanced_quant/monte_carlo/exotic_payoffs_and_pricers.ipynb" cell="quanto-correlation-proof" role="exercise" */}

                 for rho in (-0.5, 0.0, 0.5)]
for rho, value in zip((-0.5, 0.0, 0.5), quanto_values, strict=True):
    adjusted_drift = 0.03 - 0.01 - rho * 0.20 * 0.10
