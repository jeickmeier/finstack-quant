<DeskContext question="There is no convenient formula for this payoff. How do we price it, and what does the error bar actually cover?">

A desk receives a payoff that depends on simulated market states. Before extending the payoff, establish that the process has the right mean, the vanilla contract agrees with its analytical benchmark within sampling uncertainty, and the reported sample count means what you think it means. Your deliverable is a reproducible price-and-error sheet with path counts, seeds, a variance-reduction comparison and a separate statement of model limitations.

Use the analytical equity-option conventions from [lesson 2.4](/learn/2.4): decimal annual rates, continuous dividend yield, annual volatility and time in years. These are controlled risk-neutral examples, not forecasts of the equity risk premium.

</DeskContext>

<Standard>

### A price is an expectation; its estimator is random

For constant rate $r$, a payoff $H$ at time $T$ has model price $V=e^{-rT}\mathbb E_Q[H]$. With independent discounted payoffs $Y_i$, estimate

$$
\widehat V_N=\frac1N\sum_{i=1}^N Y_i,\qquad
\widehat{\mathrm{SE}}=\frac{s_Y}{\sqrt N}.
$$

An approximate 95% interval is the estimate plus or minus $1.96\widehat{\mathrm{SE}}$. This uses a central-limit approximation. A single interval need not contain the benchmark, and increasing the sample size need not make that seed's realized error smaller. It does not cover the wrong contract, calibration error, time discretization or numerical overflow. [Glasserman](/references.html#glasserman-2004-monte-carlo) develops these distinctions.

Under risk-neutral GBM,

$$
S_{t+\Delta}=S_t\exp\left[(r-q-\tfrac12\sigma^2)\Delta+\sigma\sqrt{\Delta}Z\right],\quad Z\sim N(0,1).
$$

This log step samples GBM exactly at the selected times and preserves positivity. Thus the terminal mean should agree statistically with $S_0e^{(r-q)T}$. The drift in the exponent is not the expected proportional price growth: the variance correction reconciles the two. Exact grid-point sampling still leaves monitoring error for a continuously observed payoff.

### Keep four numerical choices separate

| Choice | What it controls | What it cannot establish |
| --- | --- | --- |
| Random-number construction | Philox assigns reproducible streams; Box–Muller maps suitable uniforms to normals | Correct economic assumptions |
| Path/time grid | Which states are generated or observed | A smaller sampling SE does not fix a coarse exercise grid |
| Estimator and reduction | Plain means, antithetic pair means, common random numbers; compensated summation reduces accumulation error | A better estimator does not repair payoff bias |
| Number of independent observations | Sampling precision | The number of generated trajectories can differ from this count |

The [Philox reference](/references.html#salmon-2011-philox), [Box–Muller construction](/references.html#box-muller-1958) and [Kahan summation note](/references.html#kahan-1965) explain those implementation choices. The serial/parallel reconciliation below establishes replay for this installed build, seed and inputs; it is not a promise of identical bits across every release or platform.

Sobol sequences reduce integration discrepancy for suitable problems; their coordinate ordering and dimension matter. Ordinary IID sample-variance intervals do not automatically apply to a deterministic Sobol sequence. Randomized replicates require an appropriate separate error estimate. This Python workflow uses supported fixed-model pricers and captured GBM paths. It does not expose an injectable `McEngine`, `TimeGrid` or arbitrary scheme object. [Joe–Kuo](/references.html#joe-kuo-2008-sobol) is the low-discrepancy reference.

For antithetics, the independent observation is $(Y(Z)+Y(-Z))/2$. Its variance is $[\operatorname{Var}(Y)+\operatorname{Cov}(Y(Z),Y(-Z))]/2$. Negative covariance can help; positive covariance can waste the second trajectory. Compare equal physical-path budgets and compute standard error from pair means.

A finite-difference Greek divides a difference of noisy prices by the bump. Common random numbers increase covariance between the bumped valuations, reducing the variance of that difference. A very small bump can still amplify rounding, and a large bump creates finite-difference bias.

### Stochastic volatility adds a state and a boundary

Heston replaces constant variance with a CIR process:

$$
dv_t=\kappa(\theta-v_t)dt+\xi\sqrt{v_t}\,dW_t^v,
\qquad d\langle W^S,W^v\rangle_t=\rho\,dt.
$$

The Feller condition $2\kappa\theta\geq\xi^2$ is a sufficient positivity boundary condition, not a requirement for the model to exist. A naive Euler step can become negative even when the continuous variance process cannot. Full-truncation Euler modifies the coefficients around zero; Andersen's QE scheme approximates conditional variance moments while respecting nonnegativity. Neither turns a discretized option estimator into an exact Heston price. Compare step refinement or an independent benchmark when pricing precision matters. [Heston](/references.html#heston-1993), [Andersen](/references.html#andersen-2008-heston-qe) and [Lord–Koekkoek–van Dijk](/references.html#lord-koekkoek-vandijk-2010) provide the model and scheme context.

The Little Heston Trap concerns stable evaluation of characteristic-function formulas; Broadie–Kaya concerns exact simulation under its construction. These are useful independent reference methods, not alternative Python engine parameters silently used below.

print(f"Put-call parity RHS:       {parity_rhs:.8f}")
print(f"Parity residual:           {abs(parity_lhs - parity_rhs):.2e}")

```python exec id=antithetic-pair-arithmetic role=build
from finstack_quant.models.monte_carlo import LsmcPricer
import statistics
from finstack_quant.models.monte_carlo import simulate_gbm_paths

pairs = 2048
seed = 17
discount = math.exp(-0.05)
captured = simulate_gbm_paths(100, 0.05, 0.0, 0.20, 1.0, 1, 2 * pairs, seed=seed)
terminals = [path[-1] for path in captured.paths]
plain_payoffs = [discount * max(100 - terminal, 0) for terminal in terminals]
reflection_product = (100 * math.exp(0.05 - 0.5 * 0.20**2)) ** 2
pair_payoffs = [
    0.5 * (plain_payoffs[i] + discount * max(100 - reflection_product / terminal, 0))
    for i, terminal in enumerate(terminals[:pairs])
]
print("method | estimators | simulated paths | mean | reported SE | manually calculated SE")
results = []
for antithetic, count, payoffs in [(True, pairs, pair_payoffs), (False, 2 * pairs, plain_payoffs)]:
    estimate = LsmcPricer(count, seed, False, 1, antithetic=antithetic).price_american_put(
        100, 100, 0.05, 0, 0.20, 1.0
    )
    manual_mean = statistics.mean(payoffs)
    manual_se = statistics.stdev(payoffs) / math.sqrt(count)
    print(f"{'antithetic' if antithetic else 'plain':10s} | {count:10d} | "
          f"{estimate.num_simulated_paths:15d} | {manual_mean:.6f} | "
          f"{estimate.stderr:.6f} | {manual_se:.6f}")
    results.append(estimate)
print(f"Equal-path-budget variance ratio (plain/paired): {(results[1].stderr/results[0].stderr)**2:.4f}")
```

<Exercise title="1. What does quadrupling paths buy?" question="Use 16 independent seeds at N and 4N. Compare average reported SE and root-mean-square error against Black–Scholes. Explain why one seed cannot verify a promise to halve absolute error.">

For the same payoff variance, SE scales as $N^{-1/2}$, so its population ratio is one half. The finite seed panel tests the average SE ratio within a deliberately broad interval. RMSE is an additional empirical diagnostic and remains noisy with only sixteen seeds. We do not require monotone realized absolute error for each seed.

{/* notebook-block notebook="07_advanced_quant/monte_carlo/discretization_schemes.ipynb" cell="mc-error-scaling" role="exercise" */}
```python exec id=mc-error-scaling role=exercise
import math
import statistics

reference = bs_price(100, 100, 0.05, 0.0, 0.2, 1.0, True)
scaling = []
for count in (1024, 4096):
    runs = [EuropeanPricer(count, seed, False).price_call(
        100, 100, 0.05, 0.0, 0.2, 1.0, num_steps=1
    ) for seed in range(16)]
    average_se = statistics.mean(run.stderr for run in runs)
    rmse = math.sqrt(statistics.mean((run.mean.amount - reference) ** 2 for run in runs))
    scaling.append((average_se, rmse))
    print(f"N={count}: average SE={average_se:.6f}, independent-seed RMSE={rmse:.6f}")
se_ratio = scaling[1][0] / scaling[0][0]
print(f"SE(4N)/SE(N)={se_ratio:.4f}; theoretical scale=0.5")
print(f"Observed RMSE ratio={scaling[1][1] / scaling[0][1]:.4f}")
# A broad sampling diagnostic on this fixed seed panel, not a pathwise identity.
```

<Exercise title="3. An antithetic pair that adds no information" question="Use the symmetric payoff g(Z)=Z squared. Compare plain and antithetic standard errors at an equal 8,192-trajectory budget.">

Because $g(Z)=g(-Z)$, the two payoffs are identical. Pairing 8,192 trajectories yields only 4,096 independent observations, whereas plain sampling yields 8,192. The population SE ratio is $\sqrt2$ in favor of plain sampling. This payoff is a diagnostic of estimator design, not an equity-option contract.

{/* notebook-block notebook="07_advanced_quant/monte_carlo/discretization_schemes.ipynb" cell="antithetic-even-payoff" role="exercise" */}
```python exec id=antithetic-even-payoff role=exercise
import numpy as np
from finstack_quant.models.monte_carlo import simulate_gbm_paths

sample = simulate_gbm_paths(100, 0.05, 0, 0.2, 1, 1, 8192, seed=23)
terminal = np.asarray(sample.paths)[:, -1]
z = (np.log(terminal / 100) - (0.05 - 0.5 * 0.2**2)) / 0.2
# g(z)=z^2 is unchanged under z -> -z. Two reflected trajectories yield only one observation.
plain_payoffs = z**2
pair_means = (z[:4096]**2 + (-z[:4096])**2) / 2
plain_se = plain_payoffs.std(ddof=1) / np.sqrt(8192)
paired_se = pair_means.std(ddof=1) / np.sqrt(4096)
print(f"Same 8192 raw-path budget: plain SE={plain_se:.5f}, paired SE={paired_se:.5f}")
print(f"Observed ratio={paired_se/plain_se:.3f}; population prediction=sqrt(2)")
```
