<DeskContext question={"The trade makes money on paper. What does it cost to hold?"}>

Value the payer swap and protection-buying CDS in one explicitly designated teaching bilateral netting set. Reconcile their sensitivity mapping before comparing initial margin methods. Then calculate variation margin, regulatory-capital measures and funding adjustments. These are different quantities with different purposes; adding them indiscriminately to trade notional would be meaningless.

Complete three mandatory sessions: risk mapping, margin and capital, then XVA and decision exercises. This is an auditable calculation with pinned embedded parameters, not a claim of regulatory approval or complete bank-wide capital coverage.

<Standard>

Variation margin collateralizes current mark-to-market under CSA terms. Initial margin protects against potential adverse moves during closeout. Schedule and SIMM are bilateral approaches for non-centrally cleared derivatives; neither is exchange clearing margin. Exchange daily settlement is studied in V1. Legal netting eligibility is a supplied teaching assumption, not something inferred from a common counterparty name.

SIMM IR delta uses currency per basis point on its prescribed tenor grid. This implementation pins SIMM 2.6, the embedded 2023 vintage. FRTB GIRR sensitivities use currency per percentage point, so the same derivative is 100 times the per-bp amount. Credit-spread delta is also scaled explicitly before FRTB. A string rename of a generic risk bucket cannot establish these conventions. Reprice directly on the target grids and retain position quantity, full contractual notional, currency, factor, tenor, sign and bump size in every row.

The IR experiment inserts all target knots while retaining original interpolation breakpoints, then applies a triangular nodal zero/forward-rate shock. A zero bump must preserve PV. For CDS spread delta, rebuild the calibrated credit curve from bumped quotes on 1Y/2Y/3Y/5Y/10Y targets. The missing 2Y quote is a disclosed synthetic par quote from the original curve; all original quotes remain calibration anchors. Its small base-price drift is measured separately from sensitivity. Residual credit-sector classification is explicit because this exercise does not infer a detailed issuer sector.

A single SIMM sensitivity below concentration thresholds has IM equal to absolute sensitivity times its risk weight. Multiple factors require correlations and concentration treatment in the native engine. Schedule IM starts with asset-class/notional/maturity rates and applies the netting-set reduction $0.4+0.6NGR$. For this mixed asset-class set, compute gross class charges natively and show the aggregate NGR arithmetic. Drop-one marginal IM changes need not sum to total IM.

SA-CCR estimates exposure at default, $EAD=\alpha(RC+PFE)$. FRTB estimates market-risk capital and has separate delta, vega, curvature, default-risk and residual-risk concepts. The executable book case below covers the two trades' GIRR/credit delta; the regulatory-capital lab supplies the remaining explicit illustrative components. XVA uses exposure, hazard, discounting and funding assumptions: CVA is counterparty loss, DVA own-default benefit, FVA funding, and MVA funding of segregated IM. These illustrative profiles are assumptions, not a simulated exposure forecast.

The visible table preserves OIS and SOFR source factors, but the native SIMM and FRTB GIRR sensitivity containers key interest-rate inputs by currency and tenor. Adding both curves therefore nets them at that key; a separate subcurve-basis treatment is unavailable through these containers. The resulting charge is an illustrative simplified native calculation. It is not a complete subcurve-sensitive regulatory calculation.

Schedule residual maturity and SA-CCR start/end dates are derived from the same priced contracts: the IRS runs from 15 April 2025 to 15 April 2028, and the CDS ends on 20 March 2030. The IM profile uses an assumed linear decay to the longest actual maturity; it does not claim to reprice future margin on each date.

### Session 1: directly price the risk mapping

One swap position unit contains USD 2m notional. The discount and forward curve roles remain separate in the mapping. Central differences use ±1bp. Preserve all interpolation knots so adding target-grid nodes cannot itself manufacture a price move; the zero-shock check is USD 1e-6.

{/* notebook-block notebook="07_advanced_quant/margin_collateral_and_xva.ipynb" cell="margin-proof-1" role="build" */}
```python exec id=margin-proof-1 role=build
import copy
import json
import math

import numpy as np
import pandas as pd

from _shared.analyst_book import AS_OF, build_market, instruments
from finstack_quant.core.market_data import MarketContext
from finstack_quant.margin import FrtbSbaEngine, FrtbSensitivities, SimmCalculator, SimmSensitivities
from finstack_quant.valuations.instruments import price_instrument

market = build_market("rates")
swap = json.dumps(instruments("rates")["USD-PAYER-IRS"])
original_market = json.loads(market.to_json())
quantity = 1.0  # One position unit already contains USD 2m contractual notional.
grid_simm = dict(zip(["2W", "1M", "3M", "6M", "1Y", "2Y", "3Y", "5Y", "10Y", "15Y", "20Y", "30Y"], [14/365, 1/12, .25, .5, 1, 2, 3, 5, 10, 15, 20, 30]))
grid_frtb = dict(zip(["0.25Y", "0.5Y", "1Y", "2Y", "3Y", "5Y", "10Y", "15Y", "20Y", "30Y"], [.25, .5, 1, 2, 3, 5, 10, 15, 20, 30]))


def target_market(curve_id, grid, selected, bump_decimal):
    """Apply a disclosed nodal triangular rate shock directly on the target grid."""
    payload = copy.deepcopy(original_market)
    target = next(curve for curve in payload["curves"] if curve["id"] == curve_id)
    # Preserve every original interpolation breakpoint, adding target-grid nodes.
    times = sorted(set([knot[0] for knot in target["knot_points"]] + list(grid.values())))
    original = market.get_discount(curve_id) if target["type"] == "discount" else market.get_forward(curve_id)
    assert target["interp_style"] in {"log_linear", "linear"}, "This proof requires exact knot insertion for the source interpolation."
    weights = [float(label == selected) for label in grid]
    knots = []
    for time in times:
        weight = float(np.interp(time, list(grid.values()), weights))
        value = original.df(time) * math.exp(-bump_decimal * time * weight) if target["type"] == "discount" else original.rate(time) + bump_decimal * weight
        knots.append([time, value])
    target["knot_points"] = knots
    # These are curve-space sensitivity markets, not recalibrated quote scenarios.
    target["rate_calibration"] = None
    return MarketContext.from_json(json.dumps(payload))
```
