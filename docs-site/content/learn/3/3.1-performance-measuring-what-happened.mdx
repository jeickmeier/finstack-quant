<DeskContext question={"The fund returned 11%. Was that good?"}>

First ask whose return is being measured. A portfolio manager controls investments; an investor also controls the timing and size of subscriptions. A correct performance report distinguishes those decisions and names the benchmark and observation window. This lesson uses three periods of native book valuations, including trades, external flows and contractual payments. A separate controlled experiment shows what a headline ratio can hide.

Complete both sessions: reconstruct the cash ledger and flow-neutral return, then evaluate risk-adjusted and benchmark-relative measures. Three quarterly observations demonstrate the arithmetic; they cannot establish persistent skill.

</DeskContext>

<Standard>

An internal trade exchanges cash for an asset and does not create wealth. An external subscription increases NAV without creating investment profit. Coupon and principal receipts move from the position into settled cash; omitting either side produces artificial losses or double counting. Convert EUR payments to USD once, at the explicitly dated FX quote. The ledger assumes settled cash earns no further interest and ignores transaction costs; projected derivative cashflows are teaching inputs rather than a historical trade confirmation system.

For each interval between external flows, compute end wealth divided by beginning wealth. Link the factors to obtain $R_{TW}=\prod_j(1+r_j)-1$. Value immediately before and after every flow. Modified Dietz instead estimates $R=(V_1-V_0-\sum C_j)/(V_0+\sum w_j C_j)$, where $w_j$ is the fraction of the period remaining. It is useful when intraperiod marks are unavailable, but it is not generally identical to exact linking. XIRR solves the dated investor cashflow NPV equation and annualizes on actual days over 365; contributions are negative and terminal wealth positive from the investor's perspective.

For equally spaced quarterly returns, sample volatility is $s\sqrt{4}$ and the zero-rate Sharpe ratio is $4\bar r/(s\sqrt{4})$. CAGR compounds geometric growth. Those are different annualization operations. Sortino uses downside deviation; Calmar divides annualized geometric growth by maximum drawdown magnitude. Neither is a universal substitute for reading the return path. Drawdown depth, calendar-day duration and recovery describe different costs of holding an investment.

Tracking error is the annualized standard deviation of active returns, and information ratio divides annualized mean active return by that tracking error. Capture ratios condition on positive or negative benchmark periods and use geometric annualization. Batting average counts periods of outperformance without measuring their size. The benchmark in this fixture is explicitly illustrative. Every return shown below is a decimal fraction; monetary ledgers are USD.

</Standard>

### Session 1: reconstruct the account

The source factory supplies dated holdings, market snapshots and events. The calculation prices the holdings, settles due payments, funds purchases and observes NAV around subscriptions. Its visible reconciliations separately check trade self-financing, external-flow changes, linked returns and the XIRR residual. Monetary comparisons use a USD 1e-8 reconciliation tolerance for this float-valued analytics ledger; the XIRR check uses the native scale-normalized 1e-8 NPV tolerance.

{/* notebook-block notebook="03_analytics/performance_analytics.ipynb" cell="dated-native-performance" role="build" */}
```python exec id=dated-native-performance role=build
import json
import math
from datetime import date, timedelta
import pandas as pd
from pytest import approx
from _shared.analyst_history import performance_history, history_events, history_market, history_spec, history_quotes
from finstack_quant.portfolio import (
    Portfolio, aggregate_full_cashflows, value_portfolio, twrr_modified_dietz, twrr_linked_json, mwr_xirr,
)
history = performance_history()
history_dates = (date.fromisoformat(history[0]['start']), *(date.fromisoformat(period['end']) for period in history))
events = history_events()
start_date, end_date = history_dates[0], history_dates[-1]
initial_market = history_market(start_date)
initial_spec = history_spec(start_date)
initial_book = Portfolio.from_spec(json.dumps(initial_spec))
initial_nav = value_portfolio(initial_book, initial_market, metrics=[]).total_value
initial_cashflows = json.loads(aggregate_full_cashflows(initial_book, initial_market).to_json())["events"]
payment_dates = {
    date.fromisoformat(event["date"])
    for event in initial_cashflows
    if start_date < date.fromisoformat(event["date"]) <= end_date
}
timeline = sorted(
    payment_dates
    | set(history_dates[1:])
    | {date.fromisoformat(event["date"]) for event in events}
)
nav_rows = [{"date": start_date.isoformat(), "native_positions_usd": initial_nav, "settled_cash_usd": 0.0, "total_nav_usd": initial_nav}]
flow_rows = []
cash, segment_start, factor = 0.0, initial_nav, 1.0
period_begin, period_flows, returns, dietz_returns = initial_nav, [], [], []
investor_flows = [{"date": start_date.isoformat(), "amount": -initial_nav}]
settled_positions = set()
for when in timeline:
    market = history_market(when)
    if when in payment_dates:
        held = history_spec(when - timedelta(days=1))
        held["as_of"] = when.isoformat()
        payments = json.loads(aggregate_full_cashflows(Portfolio.from_spec(json.dumps(held)), market).to_json())
        for payment in payments["events"]:
            if payment["date"] == when.isoformat():
                amount = float(payment["amount"]["amount"])
                if payment["amount"]["currency"] == "EUR":
                    amount *= history_quotes(when)["eur_usd"]
                cash += amount
                settled_positions.add(payment["position_id"])
    spec = history_spec(when)
    valuation = value_portfolio(Portfolio.from_spec(json.dumps(spec)), market, metrics=[])
    wire = json.loads(valuation.to_json())
    for event in (event for event in events if event["date"] == when.isoformat()):
        if event["type"] == "trade":
            position = next(
                position for position in spec["positions"] if position["instrument_id"] == event["instrument_id"]
            )
            unit_value = float(wire["position_values"][event["instrument_id"]]["value_base"]["amount"])
            unit_value /= position["quantity"]
            trade_cost = event["quantity_change"] * unit_value
            before_trade = valuation.total_value - trade_cost + cash
            cash -= trade_cost
        else:
            before_flow = valuation.total_value + cash
            factor *= before_flow / segment_start
            cash += event["amount"]
            segment_start = valuation.total_value + cash
            flow_rows.append({"date": event["date"], "before_usd": before_flow, "flow_usd": event["amount"], "after_usd": segment_start})
            period_flows.append(event)
            investor_flows.append({"date": event["date"], "amount": -event["amount"]})
    nav = valuation.total_value + cash
    if when in history_dates[1:]:
        nav_rows.append({"date": when.isoformat(), "native_positions_usd": valuation.total_value, "settled_cash_usd": cash, "total_nav_usd": nav})
        returns.append(factor * nav / segment_start - 1.0)
        period = history[len(returns) - 1]
        start, end = date.fromisoformat(period["start"]), date.fromisoformat(period["end"])
        dietz_returns.append(
            twrr_modified_dietz(
                json.dumps({
                    "beginning_market_value": period_begin,
                    "ending_market_value": nav,
                    "cashflows": [
                        {
                            "amount": flow["amount"],
                            "fraction_of_period_remaining": (end - date.fromisoformat(flow["date"])).days
                            / (end - start).days,
                        }
                        for flow in period_flows
                    ],
                })
            )
        )
        period_begin, segment_start, factor, period_flows = nav, nav, 1.0, []
investor_flows.append({"date": end_date.isoformat(), "amount": nav})
years = (date.fromisoformat(history[-1]["end"]) - date.fromisoformat(history[0]["start"])).days / 365.0
linked = json.loads(twrr_linked_json(json.dumps(returns), years))
xirr = mwr_xirr(json.dumps(investor_flows))
anchor = date.fromisoformat(investor_flows[0]["date"])
npv = sum(
    flow["amount"] / (1 + xirr) ** ((date.fromisoformat(flow["date"]) - anchor).days / 365.0)
    for flow in investor_flows
)
# Native XIRR normalizes cash amounts before applying its 1e-8 tolerance.
print("Dated native valuations and settled USD cash")
print(pd.DataFrame(nav_rows).to_string(index=False))
print("Valuations immediately around each external flow")
print(pd.DataFrame(flow_rows).to_string(index=False))
print(pd.DataFrame({"period_end": history_dates[1:], "linked_subperiod_return": returns, "modified_dietz": dietz_returns}).to_string(index=False))
print({"linked_return": linked["cumulative"], "annualized_xirr": xirr, "normalized_xirr_npv_residual": npv / max(abs(flow["amount"]) for flow in investor_flows)})

```

### Session 2: interpret the measurement

The native analytics object receives the derived returns with `frequency="quarterly"`. We independently verify volatility, Sharpe and tracking error to 1e-12 in return units. The first row of the wealth plot is the initial unit investment, so the first return is not lost. An undefined ratio in a zero-downside or zero-variance window must be discussed as undefined rather than presented as evidence of superior performance.

z = np.array([-3.0, -1.0, -0.5, 0.0, 0.5, 1.0]*4)
z = (z-z.mean())/z.std(ddof=1)
fund_a = 0.006 + 0.025*z
fund_b = 0.006 - 0.025*z
funds = Performance.from_returns(pd.DataFrame({"A":fund_a,"B":fund_b},index=pd.date_range("2023-01-31",periods=24,freq="ME")),frequency="monthly")
comparison = pd.DataFrame({m:getattr(funds,m)() for m in ["sharpe","sortino","calmar","max_drawdown","cagr"]})
print(comparison.to_string())
print("Same sample mean and variance do not imply the same downside distribution or compounded drawdown.")

<CheckYourself>

- Can a subscription change NAV while leaving investment return unchanged? Yes: subtract the flow or split the observation immediately around it.
- Is a coupon an external flow? No. It belongs in investment profit and then settled cash.
- Does a higher information ratio prove skill? No. Benchmark choice, sample length and uncertainty remain essential.
- What would invalidate this report? Missing payments, wrong FX direction, omitted flow-date valuations, incorrect frequency or an unexplained residual. Repair those inputs before discussing ratios.
