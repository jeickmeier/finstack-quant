### Quantiles, tails and signs

At confidence $c$, return VaR is the lower $(1-c)$ quantile of returns. These APIs report an adverse return as a negative number. A loss-positive presentation usually negates it. Do not silently change the sign while comparing historical returns with dollar-risk decomposition.

The historical quantile here uses R-7 interpolation: sort $n$ observations, set $h=(n-1)(1-c)$, and interpolate between the adjacent order statistics. The current historical `expected_shortfall` estimator averages every observation at or below that threshold. With a continuous sample and few ties this is a useful empirical tail summary. With a large probability mass at the threshold, it can include more than exactly the worst $(1-c)$ probability mass.

The coherent loss-positive Expected Shortfall definition is

$$
\mathrm{ES}_c(L)=\frac1{1-c}\int_c^1 q_u(L)\,du.
$$

That definition includes the correct fraction of any threshold mass. It is the ES used in the subadditivity result, not an arbitrary closed-threshold average on a discrete distribution. The distinction matters in the explicit counterexample below. [Artzner and coauthors](/references.html#artzner1999CoherentRisk) and [Quantitative Risk Management](/references.html#mcneil-frey-embrechts-qrm) provide the risk-measure context.

For additive IID Gaussian daily returns with mean $\mu$ and volatility $\sigma$, return VaR over $h$ periods is

$$
q_{1-c,h}=h\mu-z_c\sigma\sqrt h.
$$

Changing confidence requires changing $z_c$; changing horizon also changes drift. This approximation assumes stationary independent increments, fixed exposures and an additive return/P&L representation. Serial dependence, jumps, nonlinear options, changing positions and compounding can invalidate square-root-of-time scaling.

Cornish–Fisher adjusts a normal quantile using sample skewness and kurtosis. It can improve a local approximation on one sample, but unstable higher moments and extreme quantiles can produce unreliable or invalid results. Finite output and closeness to one empirical quantile do not establish predictive accuracy. Use the [original expansion](/references.html#cornishFisher1937) and [moment-estimation discussion](/references.html#joanesGill1998) to interpret the correction. The Gaussian comparison here uses sample moments, not a RiskMetrics EWMA forecast.

### A factor fit describes aligned variation

Regress returns on a constant and aligned factor returns:

$$
r_t=\alpha+\boldsymbol\beta^\top\mathbf f_t+\epsilon_t.
$$

Check date alignment, missing values, units, rank and residual orthogonality before interpreting beta or $R^2$. The single benchmark beta is covariance divided by benchmark variance; the multivariate coefficients condition on the other factors. The native regression expects factors already expressed as excess returns; its default `return_kind="excess"` leaves the dependent series unchanged. This fixture uses zero risk-free return for the comparison. For total returns, specify that convention and the annual risk-free rate consistently. High $R^2$ is descriptive fit, not causal identification or evidence of alpha. [Fama–French](/references.html#fama-french-1993) motivates factor descriptions without making this synthetic three-factor panel a Fama–French dataset.

Constraints such as nonnegative coefficients or coefficients summing to one change the regression problem. They can encode a holdings interpretation but bias an unrestricted return fit, and unconstrained OLS residual identities need not survive. The supported `Performance.multi_factor_greeks` path here is unrestricted; it has no coefficient-constraint parameter. Do not reinterpret its betas as long-only portfolio weights.

With factor exposure vector $b$, covariance $\Sigma$ and an explicit horizon, systematic variance is $b^\top\Sigma b$. Dollar exposures require covariance in matching factor units. Include residual risk separately; a systematic-only answer is not total book risk. [Ledoit–Wolf shrinkage](/references.html#ledoitwolf2004) stabilizes covariance toward a structured target; positive definiteness does not prove the target is economically adequate.

### Credit calibration has a second set of units

A spread-return factor model is not the same object as the equity-return regression. The native credit fixture takes decimal spread observations and calibrated outputs expose spread-factor units in basis points. Duration-times-spread weighting uses spread duration multiplied by spread in the matching convention. [Ben Dor and coauthors](/references.html#ben-dor-2007-dts) explain the relative-spread-risk intuition.

Calibrated factors depend on hierarchy, issuer tags, minimum bucket support, observation frequency and weighting. A requested bucket may be pruned when it lacks enough names. A saved model records those choices so a later decomposition can use the same factor definitions.

The covariance returned by this calibration is annualized. Its `OneStep` wrapper exposes that stored covariance; `NSteps(12)` literally scales it by twelve. It is not an instruction to annualize monthly covariance a second time. Read the calibration frequency and result convention together.

### 2. Make skewness matter, then expose a discrete tail trap

The controlled skewed sample applies a quadratic transformation to normal draws. The normal, historical and Cornish–Fisher answers differ because they summarize different information. The code requires finite distinct results but does not reward whichever method happens to match one quantile most closely.

Now give each of two positions a 10% loss in four of one hundred equiprobable states, with disjoint loss states. Each position's 95% VaR is zero; their combined VaR is a 10% loss. This violates VaR subadditivity. Exact ES averages five worst states and gives 8%, 8% and 10%, which satisfies subadditivity. The API's closed-threshold averages include the many zero-loss ties for the separate positions and therefore differ from exact-mass ES.

{/* notebook-block notebook="03_analytics/risk_and_factor_analytics.ipynb" cell="var-nonsubadditivity" role="build" */}
```python exec id=var-nonsubadditivity role=build
# One hundred equally likely dollar-loss states; four A defaults and four different B defaults.
loss_a = np.zeros(100); loss_a[:4] = 0.1
loss_b = np.zeros(100); loss_b[4:8] = 0.1
state_returns = pd.DataFrame({"A":-loss_a,"B":-loss_b,"AplusB":-(loss_a+loss_b)},index=pd.bdate_range("2025-01-01",periods=100))
discrete = Performance.from_returns(state_returns,frequency="daily")
var_values = discrete.value_at_risk(0.95)
assert var_values["A"] == var_values["B"] == 0 and var_values["AplusB"] == -0.1
# Exact 95% ES averages exactly five worst equiprobable states, including partial threshold mass if needed.
exact_es_a = np.sort(loss_a)[-5:].mean()
exact_es_b = np.sort(loss_b)[-5:].mean()
exact_es_sum = np.sort(loss_a+loss_b)[-5:].mean()
assert exact_es_sum <= exact_es_a+exact_es_b
print("Loss-positive VaR:",(-var_values).to_dict())
print("Exact tail-mass ES:",{"A":exact_es_a,"B":exact_es_b,"AplusB":exact_es_sum})
print("API closed-threshold tail averages:",(-discrete.expected_shortfall(0.95)).to_dict())
print("Ties change the included probability mass. The API estimate is not the exact-mass ES used in the coherence theorem.")
```

<Exercise title="1. Change 95%/one day into 99%/ten days" question="Derive the 99% ten-day Gaussian return quantile from the daily mean and sample volatility. Compare it with the naive 95% VaR times square root of ten and state the assumptions.">

Use $10\mu-z_{0.99}\sigma\sqrt{10}$, not the 95% quantile multiplied by $\sqrt{10}$. Mean scales linearly and volatility with square root only under the stated IID additive-Gaussian assumptions. The native result and explicit formula agree within $10^{-9}$ in return units. The incorrect shortcut keeps the wrong confidence level and handles drift incorrectly.

```python exec id=gaussian-horizon-scaling role=exercise

mu = returns.mean(); sigma = returns.std(ddof=1)
z99 = NormalDist().inv_cdf(0.99)
manual_ten_day = 10 * mu - z99 * sigma * math.sqrt(10)
native_ten_day = float(performance.parametric_var(0.99,horizon_periods=10).iloc[0])

naive = measures["normal_var"] * math.sqrt(10)
assert abs(naive-native_ten_day) > 1e-4
print(f"99%/10-period Gaussian return VaR={native_ten_day:.6%}")
print(f"Incorrect 95%/1-period sqrt(10) shortcut={naive:.6%}")
```

<Exercise title="3. Recover a normal ES back-of-envelope" question="For a zero-mean normal return with 1% daily volatility, derive 95% ES and its ratio to 95% VaR, then compare with native parametric ES decomposition.">

With $z_c=\Phi^{-1}(c)$ and standard-normal density $\phi$, return ES is $-\sigma\phi(z_c)/(1-c)$, while return VaR is $-z_c\sigma$. Their magnitude ratio is approximately 1.254 at 95% confidence. That multiplier is not universal: it changes with confidence, distribution and nonzero mean. The assertion uses the continuous normal reference, so there is no tied-threshold-mass ambiguity.

{/* notebook-block notebook="03_analytics/risk_and_factor_analytics.ipynb" cell="normal-es-reference" role="exercise" */}
```python exec id=normal-es-reference role=exercise
from finstack_quant.models.factor.risk import parametric_es_decomposition
from statistics import NormalDist

alpha, daily_sigma = 0.95, 0.01
z = NormalDist().inv_cdf(alpha)
phi = math.exp(-0.5*z*z)/math.sqrt(2*math.pi)
expected_normal_es = -daily_sigma * phi/(1-alpha)
es_reference = parametric_es_decomposition(["unit_exposure"],[1.0],[[daily_sigma**2]],alpha)
assert abs(es_reference.portfolio_es-expected_normal_es) < 1e-9
print(f"Zero-mean normal VaR={es_reference.portfolio_var:.6%}; ES={es_reference.portfolio_es:.6%}")
print(f"ES/VaR magnitude ratio={phi/((1-alpha)*z):.6f}; this ratio depends on confidence and distribution.")
```
