<DeskContext question={"Rates up 100bp, CDS quotes up 50bp, equities down 15%: what happens, and what did we hold fixed?"}>

A stress number is incomplete without the shock definition. Moving zero rates, moving calibration quotes and moving hazard rates produce different experiments. This lesson writes the operations before applying them, preserves the original market, and reprices the actual holdings. It also distinguishes instantaneous shocks from a holding-period return.

The credit-extension exercise is a required forward comparison using the prepared fixture. You can execute it now without taking the credit track; that track later explains the additional contracts in detail.

</DeskContext>

<Standard>

One basis point is 0.0001 in a decimal rate. A parallel continuously compounded zero-rate shift $b$ transforms $DF(t)$ into $DF(t)e^{-bt}$. A quote-space calibration shock instead changes quoted instruments and rebuilds curves; the resulting zero-rate movement need not be exactly parallel. Credit quotes require recalibration, and changing discounting can invalidate replay metadata that was calibrated against the old curve.

Define exactly which factor changes and which remains fixed. The first experiment shifts only the USD discount curve and keeps the hazard curve fixed. PV-only strict portfolio calculation avoids requesting a quote-space credit-risk measure against stale discounting. The composite quote experiment rebuilds OIS and CDS curves together and then shocks the named equity spot. It does not claim to be the same rate experiment.

At small shock sizes, a matched central-difference Taylor approximation is $\Delta V\approx D_{bp}b+\tfrac12 C_{bp^2}b^2$. Its risk factors, curves, positions and bump units must match full repricing. Higher-order effects grow at large shocks; a residual is useful information, not a reason to force the approximation to match.

Scenario composition preserves the specified operations and order. Additive shifts on one unchanged zero curve commute. Calibration, time roll, and other state-dependent operations need not. Previewing a template does not establish that it is suitable for this book or that its named historical episode is an observed market-data replay.

Historical replay values a declared holding set on dated market snapshots. It does not automatically account for subscriptions, trades or all settlement conventions. Use a no-flow/no-payment window here and the full cash ledger in lesson 3.1 for account performance. Horizon returns additionally roll time and include investment carry under the specified convention.

The independent 5 bp repricing checks the local Taylor approximation within USD 0.01 in this fixture. The 100 bp residual is required to exceed USD 1 and the smaller-shock residual. This documents higher-order error for this particular book and shock; it is not a universal monotonic-error rule for every portfolio.

</Standard>

### Session 1: define the shock and compare full repricing

Preview the serialized typed operations and validate the scenario. The 100bp shock is compared with composed 40bp and 60bp shifts. The book's own ±1bp valuations supply the first and second differences; no unrelated duration is substituted. Original market serialization must remain unchanged.

{/* notebook-block notebook="06_scenarios/scenarios_and_stress_testing.ipynb" cell="base-book-scenario" role="build" */}
```python exec id=base-book-scenario role=build
from datetime import date
import json
import math
from _shared.analyst_book import build_book, build_market
from finstack_quant.portfolio import value_portfolio
from finstack_quant.scenarios import ScenarioSpec, OperationSpec, CurveKind, compose_scenarios, validate_scenario_spec, apply_scenario_to_market
AS_OF = date(2025, 1, 15)
book, market = build_book("base"), build_market("base")
unchanged = market.to_json()
base = value_portfolio(book, market, metrics=[]).total_value
def rate_scenario(bp):
    return ScenarioSpec("usd-discount-shock", [OperationSpec.curve_parallel_bp(CurveKind.discount(),"USD-OIS",bp)], f"USD discount +{bp}bp")
def reprice(bp):
    applied = apply_scenario_to_market(rate_scenario(bp), market, AS_OF)
    result = value_portfolio(book, applied.market, strict_risk=True, metrics=[])
    report = applied.report
    return result.total_value
scenario = rate_scenario(100)
print("Previewed operations:",json.loads(scenario.to_json())["operations"])
composed = compose_scenarios([rate_scenario(40),rate_scenario(60)])
compound_market = apply_scenario_to_market(composed, market, AS_OF)
compound_value = value_portfolio(book, compound_market.market, strict_risk=True, metrics=[])
up, down = reprice(1), reprice(-1)
signed_dv01 = (up-down)/2
curvature_per_bp2 = up-2*base+down
rows=[]
for bp in [1,5,25,100]:
    exact = reprice(bp)-base
    taylor = signed_dv01*bp+0.5*curvature_per_bp2*bp**2
    rows.append({"bump_bp":bp,"full_pnl_usd":exact,"taylor_pnl_usd":taylor,"residual_usd":exact-taylor})
small=next(row for row in rows if row["bump_bp"]==5)
large=next(row for row in rows if row["bump_bp"]==100)
# Independent 5 bp repricing: Taylor approximation within one USD cent in this fixture.
# Higher-order error is material at 100 bp for this same fixed-hazard experiment.
print("Matched scenario P&L:",rows)
```

The Taylor residual is reported in USD for 1, 25 and 100bp. Do not require a universally monotone error pattern across instruments; inspect the observed approximation error and any option exercise changes.

### Session 2: recalibration, replay and time roll

The composite changes OIS calibration quotes by 100bp and CDS quotes by 50bp, rebuilds their curves together, and reduces `SPX-SPOT` by 15%. This preserves a coherent quote replay recipe. The template is printed before any attempted application. The dated replay uses four weekly synthetic snapshots within a quiet contractual window and must have no skipped dates.

{/* notebook-block notebook="06_scenarios/scenarios_and_stress_testing.ipynb" cell="quote-composite-and-history" role="build" */}
```python exec id=quote-composite-and-history role=build
from datetime import date,timedelta
import pandas as pd
from _shared.analyst_book import calibration_envelope, instruments
from _shared.analyst_history import history_market
from finstack_quant.calibration import calibrate
from finstack_quant.portfolio import Portfolio, replay_portfolio
from finstack_quant.scenarios import build_from_template, list_builtin_templates, compute_horizon_return
# Quote-space stress rebuilds discount and hazard curves together. It is not an exact parallel zero shift.
quoted=calibration_envelope("base")
quote_changes=[]
for quote in quoted["market_data"]:
 if quote["kind"]=="rate_quote":
  quote["rate"]+=.01;quote_changes.append({"kind":"OIS quote","shock":"+100bp"})
 elif quote["kind"]=="cds_quote":
  quote["spread_bp"]+=50;quote_changes.append({"kind":"CDS quote","shock":"+50bp"})
print("Quote-space operation preview:",quote_changes)
calibrated=calibrate(quoted).market
composite_market=build_market("base")
composite_market.insert(calibrated.get_discount("USD-OIS"));composite_market.insert(calibrated.get_hazard("ACME-HZD"))
equity_shock=ScenarioSpec("equity-down",[OperationSpec.equity_price_pct(["SPX-SPOT"],-15)])
applied=apply_scenario_to_market(equity_shock,composite_market,AS_OF)
composite_value=value_portfolio(book,applied.market,metrics=[],strict_risk=True)
print({"base_usd":base,"quoted_composite_usd":composite_value.total_value,"pnl_usd":composite_value.total_value-base})
print("Available templates:",list_builtin_templates())
template=build_from_template("rate_shock_2022")
print("Template preview (not a historical data observation):",template.to_json())
# Dated synthetic market history; constant holdings and no intervening payments/flows/trades.
replay_dates=[date(2025,1,16)+timedelta(days=7*k) for k in range(4)]
snapshots=[(d,history_market(d)) for d in replay_dates]
replay=replay_portfolio(book,snapshots,config={"mode":"pv_and_pnl","valuation_options":{"metrics":{"mode":"only","metrics":[]}}})
print(replay.to_dataframe().to_string(index=False))
summary=replay.summary
horizon=ScenarioSpec("one-month-hold",[OperationSpec.time_roll_forward("1M",roll_mode="calendar_days"),OperationSpec.curve_parallel_bp("discount","USD-OIS",25)])
horizon_result=compute_horizon_return(json.dumps(instruments("base")["USD-CORP"]),history_market(replay_dates[0]),replay_dates[0],horizon,method="waterfall")
print({"horizon_days":horizon_result.horizon_days,"total_return":horizon_result.total_return,"annualized_return":horizon_result.annualized_return,"carry_return":horizon_result.factor_contribution("carry")})
```

```python exec id=exercise-stage-extension-stress role=exercise
from _shared.analyst_book import book_spec
# Apply the same +100 bp USD discount-curve operation before and after the
# already introduced rates, options, and CDS stages are added to foundations.
foundations_book = build_book("foundations")
foundations_market = build_market("foundations")
foundations_before = value_portfolio(foundations_book, foundations_market, metrics=[]).total_value
foundations_shocked_market = apply_scenario_to_market(
    rate_scenario(100), foundations_market, AS_OF
).market
foundations_after = value_portfolio(
    foundations_book, foundations_shocked_market, strict_risk=True, metrics=[]
).total_value
base_after = reprice(100)
foundations_ids = [row["instrument_id"] for row in book_spec("foundations")["positions"]]
base_ids = [row["instrument_id"] for row in book_spec("base")["positions"]]
added_positions = [identifier for identifier in base_ids if identifier not in foundations_ids]
comparison = pd.DataFrame(
    [
        {
            "book_stage": "foundations",
            "position_count": len(foundations_ids),
            "before_usd": foundations_before,
            "after_usd": foundations_after,
        },
        {
            "book_stage": "base",
            "position_count": len(base_ids),
            "before_usd": base,
            "after_usd": base_after,
        },
    ]
)
comparison["pnl_usd"] = comparison.after_usd - comparison.before_usd
stage_reconciliation = {
    "foundations_are_prefix": base_ids[: len(foundations_ids)] == foundations_ids,
    "added_positions": added_positions,
    "distinct_stress_pnl_usd": float(comparison.iloc[1].pnl_usd - comparison.iloc[0].pnl_usd),
}
print(comparison.to_string(index=False))
print(stage_reconciliation)
print("Same market operation; the added IRS, option, and CDS change portfolio stress P&L.")
```

The market operation is identical in both rows. The P&L changes because the base stage adds the payer IRS, SPX call and CDS to the already introduced foundations book. The USD curve moves while the CDS hazard curve and other market factors stay fixed, so this is a fixed-hazard scenario rather than a claim about unchanged CDS quotes.

<CheckYourself>

- Are 100bp to a zero curve and 100bp to OIS quotes identical? No: quote recalibration changes the fitted curve according to instrument coverage and interpolation.
- Can stale calibration replay be used after changing discounting? No. Rebuild consistently before quote-space risk calculations.
- Does a template name make a scenario historical evidence? No: dated source market observations are required for that claim.
- Why reprice the BBB sleeve under every stress? A base-date sleeve value would omit its stress contribution and break the combined total.
