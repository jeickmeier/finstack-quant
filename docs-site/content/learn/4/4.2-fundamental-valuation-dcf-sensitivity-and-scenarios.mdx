<Standard>

### Match the cash flow to the discount rate

Unlevered free cash flow to the firm is

$$
\mathrm{UFCF}=\mathrm{EBIT}(1-\tau)+\mathrm{D\&A}-\mathrm{Capex}-\Delta\mathrm{NWC}.
$$

It is available before servicing debt. Discount it at a consistent weighted average cost of capital,

$$
\mathrm{WACC}=w_E k_E+w_D k_D(1-\tau),\qquad w_E+w_D=1.
$$

Use market-value capital weights and annual rates consistent with the valuation assumptions. Levered equity cash flow includes financing effects and requires an equity discount rate. Subtracting interest from UFCF and also taking the debt tax shield in WACC would mix valuation frameworks. [Koller](/references.html#koller-valuation) and [Rosenbaum–Pearl](/references.html#rosenbaum-pearl-2020) explain these enterprise and financing distinctions.

The fixture assumes 65% equity at 12%, 35% debt at 7.5%, and a 25% tax rate, producing WACC 9.76875%. These are explicit teaching assumptions; the common USD-OIS market curve is not substituted for WACC. The operating model stores currency-unit scalars, so the code stamps USD at the DCF cash-flow boundary rather than silently treating arbitrary numbers as money.

### Terminal value deserves its own audit

Gordon terminal value at the terminal date is

$$
\mathrm{TV}_T=\frac{\mathrm{UFCF}_{T,\mathrm{annual}}(1+g)}{\mathrm{WACC}-g}.
$$

The cash flow must match the annual growth and discount-rate convention. Here the native DCF annualizes the quarterly terminal flow using its trailing four quarters. Applying an annual denominator to a single quarterly cash flow would understate value by a large factor. The model assumes a sustainable terminal state, and WACC must exceed terminal growth. A solver bound or validation cap is not an economic justification for the growth rate.

Discount explicit cash flows and terminal value to the same as-of date. Enterprise value then bridges to equity value by subtracting consistent net debt. Preserve what is included in debt, cash and other claims; a date mismatch can dwarf a numerical solver tolerance.

The borrower fixture has only one forecast year. Around 93% of its base EV is the present value of terminal value. This is a deliberate lesson in assumption exposure, not evidence that a one-year forecast is sufficient for underwriting. Extend the operating forecast to a defensible steady state before drawing an investment conclusion.

An exit multiple is another expression of a terminal assumption. The multiple implied by a Gordon value depends on cash conversion, WACC, growth and the chosen terminal metric. Reconciling the two methods algebraically does not independently validate either assumption against market comparables.

### Sensitivity, scenarios and an inverse valuation answer different questions

A local sensitivity changes one input around a stated baseline. A scenario changes a coherent set of assumptions; it has no probability until one is assigned. A goal seek answers which chosen input matches a target while the other assumptions stay fixed. That input is conditional on the model and may be economically implausible even when a root is found.

The lesson distinguishes perpetual terminal growth from quarterly revenue growth. Its market-price solve changes only terminal growth, while bull/base/bear scenarios change the forecast revenue driver. Calling both simply “growth” would conceal two different valuation questions.

An LBO return depends on operating value, entry and exit multiples, debt repayment, fees, distributions and investment dates. More leverage can improve a positive equity return while magnifying losses and liquidity risk. It does not independently create enterprise value. MOIC ignores time; dated IRR does not.

</Standard>

### 1. Carry native borrower UFCF into DCF

The code starts with `borrower_model()`, preserves all actual periods, and exposes forecast revenue/cost growth as native formula drivers. It asserts that this refactoring preserves every baseline UFCF value. The model has four actual quarters followed by four forecast quarters; valuation is as of 1 January 2025 and net debt reconciles to the last actual quarter.

{/* notebook-block notebook="04_statement_modeling/models/dcf_valuation.ipynb" cell="native-dcf" role="build" */}
```python exec id=native-dcf role=build
import json
import math
from pathlib import Path
import numpy as np
import pandas as pd
from _shared.borrower_model import borrower_model, borrower_vintage, PERIODS
from finstack_quant.core.money import Money
from finstack_quant.statements import ModelBuilder, Evaluator, ForecastSpec, MonteCarloConfig
from finstack_quant.statements_analytics import (
    TerminalValueSpec, evaluate_dcf, dcf_sensitivity, wacc, ScenarioSet, evaluate_scenario_set,
    SensitivityConfig, run_sensitivity, generate_tornado_entries, goal_seek, variance_bridge,
)

borrower = borrower_model()
borrower_results = Evaluator().evaluate(borrower)
valuation_builder = ModelBuilder.from_spec(borrower)
# Expose operating growth as native formula drivers. Preserve every actual and the baseline forecast.
for node, growth in [("revenue",0.02),("cogs",0.02),("opex",0.015)]:
    valuation_builder.value(f"{node}_growth",[(period,growth) for period in PERIODS])
    valuation_builder = valuation_builder.mixed(node).values(
        [(period,borrower_results.get(node,period)) for period in PERIODS[:4]]
    ).formula(f"lag({node},1) * (1 + {node}_growth)").build()
# The operating graph stores currency-unit scalars. Stamp USD once at the DCF boundary.
valuation_builder.value_money("usd_unit",[(period,Money(1,"USD")) for period in PERIODS])
valuation_builder.compute("ufcf_usd","ufcf * usd_unit")
valuation_builder.compute("total_debt","debt_end").compute("cash","cash_end")
valuation_model = valuation_builder.build()
valuation_results = Evaluator().evaluate(valuation_model)
assert all(abs(valuation_results.get("ufcf",p)-borrower_results.get("ufcf",p)) < 1e-6 for p in PERIODS)
cost_of_capital = wacc(0.65,0.12,0.35,0.075,0.25)
assert abs(cost_of_capital-(0.65*0.12+0.35*0.075*(1-0.25))) < 1e-12
terminal_growth = 0.025
terminal = TerminalValueSpec.gordon_growth(terminal_growth)
base_dcf = evaluate_dcf(valuation_model,cost_of_capital,terminal,ufcf_node="ufcf_usd",as_of="2025-01-01")
assert abs(base_dcf.enterprise_value.amount-base_dcf.net_debt.amount-base_dcf.equity_value.amount) < 0.01
assert abs(base_dcf.net_debt.amount-valuation_results.get("net_debt","2024Q4")) < 0.01
terminal_annual_ufcf = sum(valuation_results.get("ufcf",p) for p in PERIODS[4:])
terminal_undiscounted = terminal_annual_ufcf*(1+terminal_growth)/(cost_of_capital-terminal_growth)
terminal_discount_factor = base_dcf.terminal_value_pv.amount/terminal_undiscounted
explicit_pv = base_dcf.enterprise_value.amount-base_dcf.terminal_value_pv.amount
print("Forecast quarterly UFCF (USD):",[valuation_results.get("ufcf",p) for p in PERIODS[4:]])
print(f"WACC={cost_of_capital:.5%}; annual terminal UFCF={terminal_annual_ufcf:,.2f}")
print(base_dcf.to_json())
print(f"Terminal share of enterprise value={base_dcf.terminal_value_pv.amount/base_dcf.enterprise_value.amount:.2%}")
```

### 4. Solve the perpetual growth implied by a target price

Suppose the comparison equity price is USD 130 million. Add the same net debt to obtain the corresponding EV target, hold explicit cash-flow PV fixed and translate the remaining target into terminal-date value. A native formula hook exposes the Gordon relationship to `goal_seek`. Bound the terminal growth assumption from −2% to 4.5%, then reprice the solved growth through `evaluate_dcf`.

{/* notebook-block notebook="04_statement_modeling/models/dcf_valuation.ipynb" cell="implied-terminal-growth" role="build" */}
```python exec id=implied-terminal-growth role=build
goal_builder = ModelBuilder.from_spec(valuation_model)
goal_builder.value("wacc_assumption",[(p,cost_of_capital) for p in PERIODS])
goal_builder.value("terminal_growth_assumption",[(p,terminal_growth) for p in PERIODS])
goal_builder.compute("ufcf_ttm","ufcf + lag(ufcf,1) + lag(ufcf,2) + lag(ufcf,3)")
```

### 5. Separate enterprise-value creation from financing returns

The LBO uses the same borrower operating cash flows. It pins the latest-actual EBITDA explicitly because the native LBO evaluator reads its entry metric from the first model period. Entry EV is 8.5× that run-rate EBITDA, exit EV is 9× forecast run-rate EBITDA, and fees are USD 3 million. Compare USD 80 million and USD 100 million of funded debt.

{/* notebook-block notebook="04_statement_modeling/models/lbo_analysis.ipynb" cell="borrower-lbo-financing" role="build" */}
```python exec id=borrower-lbo-financing role=build
import json
import pandas as pd
from _shared.borrower_model import borrower_model, PERIODS
from finstack_quant.statements import ModelBuilder, Evaluator
from finstack_quant.statements_analytics import add_roll_forward_with_opening, evaluate_lbo
from finstack_quant.portfolio import mwr_xirr

operating = borrower_model()
operating_results = Evaluator().evaluate(operating)
entry_metric = operating_results.get("annualized_ebitda","2024Q4")
entry_cash = operating_results.get("cash_end","2024Q4")
lbo_rows = []
for funded_debt in (80_000_000.0,100_000_000.0):
    builder = ModelBuilder.from_spec(operating)
    # evaluate_lbo reads the first model period: pin the latest-actual closing metric explicitly.
    builder.value("lbo_entry_ebitda",[(p,entry_metric) for p in PERIODS])
    builder.value("lbo_forecast",[(p,float(p in PERIODS[4:])) for p in PERIODS])
    builder.value("lbo_amort",[(p,funded_debt*0.025 if p in PERIODS[4:] else 0.0) for p in PERIODS])
    builder.compute("lbo_interest","lbo_debt_beg * 0.075 / 4 * lbo_forecast")
    builder.compute("lbo_cash_change","lbo_forecast * (ufcf - lbo_interest*(1-tax_rate) - lbo_amort)")
    builder.compute("lbo_cash",f"{entry_cash} + cumsum(lbo_cash_change)")
    financed = add_roll_forward_with_opening(builder.build(),"lbo_debt",[],["lbo_amort"],funded_debt)
    financing_results = Evaluator().evaluate(financed)
    assert min(financing_results.get("lbo_cash",p) for p in PERIODS[4:]) > 0
    # All company cash is reserved for operating liquidity: no interim distribution or excess-cash credit at exit.
    result = evaluate_lbo(financed,8.5,"lbo_entry_ebitda",9.0,"annualized_ebitda","lbo_debt_end","2025Q4",[("term_loan",funded_debt)],3_000_000)
    assert result.sources_uses_balanced
    value_creation = (result.exit_metric-result.entry_metric)*8.5 + result.exit_metric*(9.0-8.5)
    debt_paydown = funded_debt-result.exit_net_debt.amount
    assert abs(result.exit_equity_proceeds.amount-result.equity_check.amount-(value_creation+debt_paydown-3_000_000)) < 0.01
    irr = mwr_xirr(json.dumps([{"date":"2025-01-01","amount":-result.equity_check.amount},{"date":"2025-12-31","amount":result.exit_equity_proceeds.amount}]))
    lbo_rows.append({"funding_usd":funded_debt,"sponsor_equity_usd":result.equity_check.amount,"debt_paydown_usd":debt_paydown,
                     "exit_equity_usd":result.exit_equity_proceeds.amount,"moic":result.moic,"dated_irr":irr})
assert lbo_rows[1]["moic"] > lbo_rows[0]["moic"]
print(pd.DataFrame(lbo_rows).to_string(index=False))
print("Higher leverage improves this positive operating/exit scenario and amplifies downside. Mandatory amortization is 2.5% per quarter; no cash sweep is assumed.")
```

Debt amortizes by 2.5% of initial funding per forecast quarter. Cash interest uses beginning debt and a 7.5% annual rate; the cash-feasibility check deducts after-tax interest and mandatory amortization from UFCF. All cash is reserved for operating liquidity: there is no interim distribution, cash sweep or excess-cash credit at exit. Consequently the exit net-debt input is gross remaining debt under this stated excess-cash convention.

The hand bridge attributes equity profit to EBITDA growth valued at the entry multiple, exit-multiple change applied to exit EBITDA, debt paydown and fees. Native sources and uses must balance. Dated XIRR uses 1 January and 31 December 2025, so it differs slightly from simply subtracting one from the one-year MOIC. Higher funding improves this positive scenario's MOIC while reducing the initial equity cushion; the sign need not survive a weaker exit scenario.

<Exercise title="3. Propagate revenue uncertainty into enterprise value" question="Generate 1,024 native statement paths for revenue growth, retain each joint quarterly UFCF path and reprice every path through native DCF. Report EV percentiles and explain what distribution they describe.">
