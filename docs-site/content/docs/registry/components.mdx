---
title: Individual components
description: Reusable forms, valuation views and market curve figures.
---

InstrumentForm and PricingParamsForm accept caller state and native validation or
option hooks. ValuationSummary and MeasuresGrid display returned values with their
currency and rounding context. CurveChart plots stored knots and labels their source;
it does not infer an interpolated curve.

Use these independently or install [the bond workbench](/docs/registry/workbench).
