---
title: Primitives
description: Controlled inputs, exact value displays, tables and shared figures.
---

Primitives own presentation and interaction. DecimalInput, MoneyInput, DateInput,
MetricPicker, JsonViewer and FinstackChart can be installed independently. They do
not price instruments. Financial values and units come from the caller or native results.

The shared theme supplies light and dark palettes, density and locally served IBM
Plex fonts. [The bond workbench](/docs/registry/workbench) composes these controls.
