# Equity, property, basket and composite methodology inventory

**Scope:** the complete assigned equity-family and umbrella composition/contract slice: **97 Rust source files**, inspected at `7e82fd03ad98346727769e88dd5ac5d84b56e9fc` on 2026-11-05. The manifest contains 74 algorithm-bearing files, 22 support files and 1 dedicated test file; there are no generated Rust files in this slice. [coverage.json](coverage.json) maps every assigned file exactly once. The 24 records below document algorithms, controls, conventions and limitations. Eighteen are **Accepted** and 6 are **Draft**.

This slice includes model adapters, their actual selection and product-specific risk behavior; the mathematical bodies of shared models, cashflows, listed-option and valuation-framework helpers are covered by those owning slices. All assigned runtime implementations were inspected, including financially material validation/defaults inside type files. Inline tests and referenced integration fixtures were inspected or located for the roles stated in each record. The original source audit ran no tests, benchmarks, builds or financial recalibrations. Acceptance and implementation reconciliation are tracked separately. Source coverage is not an independent numerical correctness certificate.

The existing [vanilla model selection ADR](0027-vanilla-option-model-selection.md) remains a related selection record; this inventory adds formulation, lifecycle, numerics, metrics, composition and discrepancies.
