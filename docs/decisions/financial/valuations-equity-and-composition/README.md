Acceptance and implementation reconciliation are tracked separately. Source coverage is not an independent numerical correctness certificate.

qualification are maintained in the
[equity and composition follow-ups](../FOLLOW_UPS.md#equity-and-composition).

boundaries; the register owns the outstanding work.
