It complements [calibration targets](../calibration-targets/README.md) and [rate-model calibration](../calibration-rate-models/README.md); their target-specific pricing kernels and fitted parameters are separate audited choices.

## Supplemental convention inputs

The quote builders read external registry data that materially determines dates and cashflows. The following four configuration files were inspected; they are supplemental inputs to the Rust-file ledger, not an independent certification of the registry contents or underlying market standards.

- [Rate-index conventions, data version 2](../../../../finstack-quant/valuations/core/data/conventions/rate_index_conventions.json): index classification, fixed/float frequencies and day counts, settlement lag, calendar/BDC, EOM, payment/reset lags and overnight compounding feed deposit/FRA/swap construction. An explicit OIS override takes precedence over per-index compounding.
- [Rate-future conventions, data version 1](../../../../finstack-quant/valuations/core/data/conventions/ir_future_conventions.json): reference-period conventions and index identity govern futures construction; the quote supplies convexity in decimal rate units, default zero.
- [CDS conventions, data version 3](../../../../finstack-quant/valuations/core/data/conventions/cds_conventions.json): family/currency lookup determines settlement and schedule conventions, standard date handling, accrued premium and protection start. Valuation convention can be explicit in build context.
- [Cross-currency conventions, data version 1](../../../../finstack-quant/valuations/core/data/conventions/xccy_conventions.json): currency-pair convention selects domestic/foreign index IDs, basis leg, settlement lag, calendars and leg schedules; explicit quote/calendar fields have the precedence documented in record009.

## Evidence and follow-up tracking

The records distinguish implemented facts from proposed rationale, suspected numerical impact and pending adoption. Solver convergence, final curve validation and quote-fit acceptance are separate gates; the framework can retain a failed report under explicitly permissive policy. A stored source curve or replay recipe does not itself establish independent pricing accuracy.

The records retain algorithm limitations and evidence boundaries. Implementation reconciliation, adoption questions and missing evidence are owned by the [calibration-framework follow-ups](../FOLLOW_UPS.md#calibration-orchestration-solvers-and-replay). No runtime remediation is part of this audit.
