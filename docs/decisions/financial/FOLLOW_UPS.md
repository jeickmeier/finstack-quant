This register owns mutable algorithm work. Records and inventories retain
formulas, observed behavior, material limitations and evidence qualifications,
and link here for action details. Each action has one authoritative entry; use
links for work owned by the central register. Record progress and completion
evidence with the owning entry instead of duplicating task lists in records.

The labels distinguish the work required:

- **Observed** (185): a static implementation, contract, dispatch or
  documentation difference. Its financial impact is not necessarily reproduced.
- **Investigate** (52): a source-derived numerical or economic concern
  requiring targeted reproduction, an independent reference or convergence
  study before a defect conclusion.
- **Decision** (281): a financial convention, supported domain, approximation,
  failure policy or result meaning requiring explicit agreement.
- **Reconciliation** (1): implementation and verification work against an
  accepted contract, without reopening that contract for adoption.
- **Evidence** (69): a particular primary-reference, empirical-calibration,
  independent-fixture or numerical-qualification gap.

These categories are not severity rankings. A decision can expose implementation
work, and an observed difference can require numerical investigation. Earlier
agreed directions remain implementation reconciliation requirements; they are
not reopened as optional choices. The [audit boundary](AUDIT_BOUNDARY.md) records
the source and evidence limits; [ADR 0026](governance/0026-methodology-decisions-and-inventory.md)
defines adoption and independent statuses.

Record closure in this register, linking to the agreed scope/rationale and
appropriate implementation or validation evidence in the owning methodology.
Applied documentation corrections are excluded unless an underlying policy or
runtime question remains. Shared-kernel issues appear at their owner; distinct
product consequences remain in their product scope.

## Core conventions

[Scope inventory](core-conventions/README.md).

- **Observed — Holiday coverage is shorter than the cache horizon.** The 1970–2150 cache does not establish complete holidays: India moving dates cover 2024–2026, Singapore 2024–2027, Matariki 2022–2052, and China dated Spring Festival/Labour Day spans 2004–2026 with estimates/bridge approximations elsewhere. Some out-of-table lunar/equinox rules contribute no holiday. Decide coverage reporting, permitted projections or errors, and refresh ownership. Include historical exceptions and whether China banking calendars may be used where weekend make-up work matters; define how incomplete coverage is surfaced to consumers. Records: [004](core-conventions/004-holiday-engine.md), [005](core-conventions/005-jurisdiction-calendars.md).

- **Observed — Calendar generator accepts weakly checked input.** Unknown JSON fields and semantic date, nth-weekday and effective-bound checks are not uniformly enforced; missing fields can select no observation or false ignore-weekends. No invalid maintained row was established. Define strict generator-domain validation and invalid-input fixtures. Records: [004](core-conventions/004-holiday-engine.md).

- **Observed — Context-dependent day counts are accepted by a context-free XIRR API.** XIRR supplies default day-count context, so Bus252, ACT/365L and ACT/ACT ICMA fail for nonempty intervals needing calendar, frequency or coupon boundaries. Choose an explicit supported list or a context-bearing contract. Records: [002](core-conventions/002-coupon-context-day-counts.md), [017](core-conventions/017-irr.md).

- **Decision — CDS schedule overrides.** CDS mode snaps to the previous quarterly twentieth but permits ordinary frequency, stub and end overrides without standard-IMM whole-quarter/maturity-grid checks. Agree which combinations represent supported CDS contracts. Records: [008](core-conventions/008-schedule-generation.md), [009](core-conventions/009-contractual-roll-dates.md).

- **Observed — Raw 30/360 helpers and high-level year fractions differ.** Raw synthetic counts do not impose the high-level equal/reversed-date policy: the ISDA termination exception can produce a nonzero identical-date raw count, while year_fraction returns zero; signed reversal clears termination. Define the intended public boundary and regression cases. Agree contract-to-variant mapping and whether high-level access to ISDA bond basis is required. Records: [003](core-conventions/003-thirty360.md).

- **Observed — Day-count evidence and complexity prose need correction.** The stored QuantLib fixture incorrectly calls 2024-02-28 leap-year February month-end, although its numerical expectation is unchanged. Its certified flag is not independently verified provenance. Bus252 prose also claims universal scanning despite prefix-cache use for built-in calendars. Correct the source descriptions and independently regenerate the reference fixture. Records: [001](core-conventions/001-actual-day-counts.md), [003](core-conventions/003-thirty360.md).

- **Observed — Rate and Bps precision boundaries.** Rate-to-bp integer conversion rounds then saturates, Bps division truncates, extreme finite percent/bp-float conversions may overflow, and checked Rate division validates the result rather than rejecting an infinite divisor. Specify overflow, truncation and accepted scalar policies and qualify boundary behavior. Records: [018](core-conventions/018-rate-units.md).

- **Decision — FX aggregate rates, authority and fallback.** PeriodAverage selects supplied aggregate quotes; inversion and cross multiplication do not calculate a mean of inverse/cross observations. Global reciprocal overrides outrank scoped direct quotes. Most provider errors allow triangulation, while invalid returned rates do not. Agree accounting-average semantics, source precedence and eligible fallback errors. Records: [013](core-conventions/013-fx-resolution-and-shocks.md).

- **Observed — FX state loading is a non-atomic merge.** load_from_state merges global/pinned overrides and can leave earlier writes after a later invalid value. Relative shocks multiply direct and divide inverse quotes, preserve provider date/policy shape and can affect derived crosses. Adopt replacement/merge atomicity and redundant-quote shock contracts. Records: [013](core-conventions/013-fx-resolution-and-shocks.md).

- **Evidence — FX market conventions need pair-specific provenance.** Qualify pair ranking, either-leg JPY/KRW/HUF 0.01 pip heuristics and T+1 exceptions against primary market specifications. Reconcile final-date USD gating for spot with the base/quote-only forward helper and calendar-EOM versus last-business-day EOM. Include validated pair coverage, calendar IDs and pair-level pip-size applicability. Records: [011](core-conventions/011-fx-date-and-quote-conventions.md).

- **Decision — Schedule failures and repairs.** MissingCalendarWarning skips adjustment, GracefulEmpty can suppress internal failures into an empty schedule, and monotonic repair logs without a ScheduleWarning. Specify eligible consumers and observable diagnostics before adopting these policies. Resolve whether equal-date schedules are empty or invalid. Records: [008](core-conventions/008-schedule-generation.md).

- **Decision — Approximate time conversion and LTM completeness.** Agree weekly 52 versus 365/7, Bus252 years-to-calendar-day tenor conversion, rounded compounding frequency, daily 252 annualization, and weekly-ID versus calendar-year daily LTM. Daily LTM checks leading coverage but permits interior gaps/duplicates; non-daily LTM does not verify observations. Define permitted valuation uses, mixed-period-kind ordering and interior-gap/duplicate expectations; justify approximation accuracy for those uses. Records: [007](core-conventions/007-tenor-date-arithmetic.md), [014](core-conventions/014-fiscal-periods-ltm.md).

- **Decision — Money rounding and currency-data authority.** Choose operation-specific rounding points, modes and scales within [ADR 0020's](conventions/0020-numerical-representation-and-rounding.md) accepted construction, precision and nonfinite-input boundaries; set Decimal/f64 error budgets and resolve same-currency nonunit conversion behavior. Records: [012](core-conventions/012-money-decimal-precision.md).

- **Decision — Cashflow signs, validation and same-day NPV.** Principal signs and noncash filtering remain caller-owned; explicit validation does not reconcile amount with rate. NPV excludes valuation-date flows yet checks currency even for excluded flows. Agree settlement/balance-date propagation and inclusion policies. - **Decision — Unique-return IRR eligibility and accuracy.** Exactly one sign change is required even if a nonconventional stream has one admissible root. - **Decision — Ratings and scorecards.** NR sits between C and D; some nonstandard suffixes normalize; representative 0–100 scores, thresholds and default 50 have no quantitative agency derivation; unknown scales default to S&P. - **Decision — Shared barrier defaults.** UpAndOut and AtHit enum defaults do not establish monitoring, touch or knock-in rebate economics. - **Evidence — Astronomical calendar generation and source provenance.** The manual lunar generator uses unpinned lunar_python for seven CSVs, with Qing Ming UTC+8 and Japanese equinox UTC+9 adjustments. The active renderer only validates/emits maintained inputs; it performs no astronomical or official-data refresh. Records: [004](core-conventions/004-holiday-engine.md), [005](core-conventions/005-jurisdiction-calendars.md).

- **Decision — Day-count selection and coupon-context domains.** Agree contract-to-convention mapping, NL/365 endpoint semantics and whether zero-length intervals require valid context. Define explicit-reference ICMA frequency/month consistency, permitted ACT/365L frequency families and the treatment of business-day adjustment beyond a nominal ICMA coupon. Records: [001](core-conventions/001-actual-day-counts.md), [002](core-conventions/002-coupon-context-day-counts.md).

- **Decision — Calendar-adjustment bounds and contractual roll anchors.** Agree downstream suitability of the fixed business-day search bound and `None` weekends-only behavior. ## Core numerics

[Scope inventory](core-numerics/README.md).

- **Observed — Interpolation documentation exceeds implemented guarantees.** Hagan–West positivity clipping is local where adjacent discrete forwards are nonnegative, despite prose saying any negative forward disables it globally. Increasing positive DFs invalidate unconditional positive-forward claims; cubic interpolation supports two points despite a four-point example. Reconcile source documentation with the actual domain. Records: [02](core-numerics/value-interpolation.md), [03](core-numerics/forward-interpolation.md).

- **Investigate — Extreme beta sampling fallback.** Finite positive shapes can overflow the Gamma sum; the fallback alpha/(alpha+beta) gives zero for alpha=beta=1e308 rather than one half by static arithmetic. Reproduce large/tiny-shape regimes, define an allowed domain and qualify endpoint fallback before changing the kernel. Include per-consumer endpoint-approximation eligibility, independently sourced distributional tails and reference provenance. Records: [14](core-numerics/beta-gamma-sampling.md).

- **Observed — Absolute epsilon and bypassable configuration.** Zero tolerance is absolute abs(x)<=epsilon, while source rationale describes a notional-relative example. Public in-memory fields can bypass constructor validation although serde rejects invalid tolerances. Reconcile units and validation boundaries. Verify consuming boundaries use the intended scale/tolerance and document economic provenance for embedded registries separately. Records: [23](core-numerics/rounding-and-config.md).

- **Observed — Tabular cross-field invariants are bypassable.** TableEnvelope public fields and derived deserialization can bypass equal-column-length and unique-name constructor checks. Canonical schema structure does not establish those invariants; define the validated entry boundary. Also reconcile higher-level resource-limit enforcement, side effects in native parallel tasks, full-recovery rejection by consumers of the shared helper, and the distinction between truncated traces and complete evidence. Records: [25](core-numerics/contracts-and-diagnostics.md).

- **Observed — Count wire round trips have asymmetric ranges.** Serialization enforces u32/i32 bounds, while deserialization accepts usize/i64, so a 64-bit input can load and fail reserialization. Agree a single wire-domain contract. Specify which financial outputs permit sentinels, canonical-version rules for future normalization changes and independent cross-language writer qualification before relying on shared content hashes. Records: [24](core-numerics/numeric-wire-and-canonical.md).

- **Observed — Time-grid validation and event mapping differ.** Uniform grids bypass the custom minimum dt of 1e-10. Required-event grids ignore invalid/out-of-range events and merge nearby events; date/time helpers separately ignore, clamp or snap. Agree strictness and event identity across construction paths. Set per-product snapping-error budgets and treatment of missing, near-coincident and out-of-horizon events. Records: [20](core-numerics/time-grids.md).

- **Decision — Solver success and caller acceptance.** LM can return Ok with MaxIterations or StepTooSmall and its accepted-step count differs from the loop budget. Brent does not validate tolerance, and bracket-width termination does not prove a small residual. Adopt per-caller status/residual/error criteria and budgets. Resolve finite explicit-bracket endpoints, valid tolerance/provider inputs, conditioning limits and a consistent diagnostic iteration-count meaning. Financial inversions must state admissible root ranges and root-selection policy; StepTooSmall is not automatically an acceptable financial fit. Records: [05](core-numerics/brent-root.md), [06](core-numerics/levenberg-marquardt.md).

- **Decision — Bernoulli feasibility and endpoint sampling.** CorrelatedBernoulli projects infeasible rho, forces zero dependence below marginal variance 1e-10, and u=1 selects the final bucket even if its mass is zero. Agree clipping and endpoint semantics with dependent credit consumers. Include impossible-event conditional fallbacks, requested/effective parameter reporting and whether near-degenerate dependence replacement is permitted. Records: [16](core-numerics/correlated-bernoulli.md).

- **Decision — Lossy LLM schemas are not validation contracts.** Projection removes assertions, weakens positional tuple types, substitutes handles for large definitions and makes object fields required. max_inline_bytes=0 has different local/external meanings. Define publication intent and require canonical validation where needed. Resolve definition-name collisions and zero-budget meanings, qualify schema/runtime invariant parity, and identify the assertions intentionally removed by each projection. Records: [26](core-numerics/schema-publication.md).

- **Observed — Expression missing-data and extreme rounding semantics.** NaN truth in and/or differs from conditional propagation, branches evaluate eagerly, shape padding uses NaN, and very negative rounding digits can underflow the scale to zero. Agree these contracts and reproduce arithmetic boundaries. Locate or add targeted unselected-branch error and extreme-digit evidence before claiming reconciliation with other evaluators. Records: [22](core-numerics/expression-evaluation.md).

- **Decision — Numerical repairs and unchecked boundaries.** Adopt quadrature tolerances, interpolation/tail/negative-forward policy, rank truncation and nearest-correlation repair-distance budgets per caller. Raw fractional covariance, piecewise queries and some scalar/fixed-integration helpers accept unchecked or nonfinite outcomes; assign validation ownership. For interpolation, distinguish each wrapper’s FlatZero meaning, extreme-extrapolation/helper preconditions and risk/calibration shape changes at clipping boundaries. For quadrature, specify absolute tolerances, order/depth and discontinuity splits, plus nonfinite fixed-integrand behavior. For matrix routines, resolve symmetry enforcement, original-correlation versus approximate-PSD requirements, original/repaired retention and option/domain/conditioning limits. For fractional covariance, choose enforced consumer-domain validation or checked shared helper signatures. For fractional covariance and piecewise coefficients, qualify cancellation/PSD error on extreme grids, tiny-interval/near-zero-kappa thresholds, finite queries/results, nonnegative steps and raw-kappa ranges. Records: [02](core-numerics/value-interpolation.md), [03](core-numerics/forward-interpolation.md), [04](core-numerics/quadrature.md), [07](core-numerics/matrix-factorization.md), [08](core-numerics/nearest-correlation.md), [19](core-numerics/fractional-covariance.md), [21](core-numerics/piecewise-coefficients.md).

Agree permitted fit domains, analytic versus trait finite-difference forward selection, and negative-source-time treatment. Records: [07](core-market/parametric-discount.md).

- **Observed — Hazard lookup and survival integration use different near-origin rules.** Survival/conditional integration skip knots at or below 1e-9, while hazard lookup uses exact ending knots. Reproduce the derivative mismatch on positive near-zero knots and choose a consistent exact-zero/tolerance contract. Agree the survival-underflow domain and numeric endpoint error policy alongside hazard-cap controls. Records: [04](core-market/hazard-survival.md).

Define minimum spacing or consistent treatment and qualify resulting hazard/price/CPI versus rate sensitivities. - **Observed — Hazard quotes and recovery changes can silently change method.** Quote input permits duplicate tenors/nonpositive spreads; failed log interpolation falls back to linear and sparse data use lambda*(1-R). Adopt rejection/fallback disclosure and quote-recalibration semantics, recovery/quote consistency, and out-of-range tenor handling. Records: [05](core-market/hazard-quotes-and-risk.md).

- **Observed — Observed values have weaker domain and availability checks.** InflationIndex accepts finite nonpositive CPI, its ratio rejects only zero base, and direct lookup does not enforce publication metadata. Specify positive-domain, overflow and point-in-time responsibilities, stale-data scope, exact-fixing eligibility, CMS tenor admissibility and scalar direct-construction guarantees; product consequences remain in rates and inflation-bond records. Records: [11](core-market/inflation-observations.md), [12](core-market/scalar-series-and-fixings.md), [22](core-market/market-change-measurement.md).

- **Decision — Forward projection and partial-reset rolling.** Point rates, fixed-panel Simpson averages and reset-grid/tenor compounded-implied rates are distinct methods. The default grid is numerical tenor, and rate-function rolling need not preserve conditional projection DFs inside an elapsed simple reset. Adopt contractual grid/roll economics, inference versus explicit conventions, and average-integration accuracy targets; obtain knot/long-horizon Simpson convergence evidence. Records: [02](core-market/forward-projection.md).

- **Decision — Curve roll reconstruction and expired grids.** Discount/forward transforms preserve source interpolation; price, CPI and basis drop retained source state on a negative cumulative offset and rebuild from surviving pillars. Rolls can fail after the last pillar despite extrapolation support. Adopt backward-roll approximation and exhausted-grid behavior, including interpolation/extrapolation scope for each commodity or volatility index. Records: [03](core-market/rate-shocks.md), [08](core-market/price-curves.md), [09](core-market/basis-spreads.md), [10](core-market/inflation-projection.md).

- **Decision — Projected versus observed CPI conventions.** Projected lag is months/12; observed monthly references use calendar months and contractual-month daily weights. FlatZero holds CPI level rather than annual inflation, multiplicative shocks scale gross annual factors, and positive seasonality factors are unnormalized. Adopt these distinctions with instrument-specific official fixtures. Records: [10](core-market/inflation-projection.md), [11](core-market/inflation-observations.md).

- **Decision — Boundary repair and stress risk.** Vol shifts floor at zero, bucket percentages below -100% collapse values while direct negative scales error, correlations clamp even negative factors to [0,1], VolIndex rejects negative shocked knots, and forward variance rejects zero. Agree signed price-shock domains, convention-specific volatility bump units, node-selection and bucket tolerances, zero-vol stress, forward-variance input semantics and zero-variance limits per consumer. Specify accepted correlation bounds, risk units, diagnostic versus blocking validation and nonmonotonic-smile treatment; correlation shape diagnostics and storage validation do not certify no arbitrage. Records: [08](core-market/price-curves.md), [14](core-market/volatility-grids-and-shocks.md), [17](core-market/forward-variance.md), [18](core-market/base-correlation.md).

- **Evidence — FX smile and SABR quote contracts.** Obtain independent fixtures for premium-unadjusted forward delta, DNS ATM and arithmetic smile BF rather than market-strangle BF. SABR storage accepts nu=0 and finite signed shifts/forwards; evaluator admissibility/interpolation must be qualified jointly with model records. Establish caller responsibility for matching delta/ATM conventions and evaluator responsibility for shifted-forward domains and quote conventions. Constructor round trips are not pricing evidence. Records: [15](core-market/fx-delta-quotes.md), [16](core-market/sabr-cube-data.md).

- **Decision — Credit-index fallback and invalidation.** Unknown issuers fall back to aggregate hazard/recovery/equal weight even when complete supplied maps are required. Records: [19](core-market/credit-index-composition.md), [20](core-market/context-lifecycle.md).

- **Decision — Context targeting, theta and replay.** Generic target precedence is curves, surfaces, scalars, then series despite namespace-only ID uniqueness. Roll ages curves only, leaving FX, surface/cube expiries, observations and dividends unchanged. Snapshots restore explicit FX quotes without providers. Adopt typed targeting, frozen-data theta and replay completeness. Records: [20](core-market/context-lifecycle.md).

- **Decision — Hierarchy overlap and market-change measurement.** Cumulative overlapping subtrees can shock one curve repeatedly; missing paths return empty. Diffs use same numeric tenors, unweighted/baseline-only grids, possible duplicate weights and different average/per-tenor tolerance handling. Raw CPI diffs can compare different latest dates. Agree empty-filter cumulative scope, missing-target diagnostics, date alignment and aggregation, baseline-grid/equality-tolerance choices, paired-source fallback and relative changes for negative or near-zero prices. Records: [21](core-market/hierarchy-selection.md), [22](core-market/market-change-measurement.md).

- **Decision — Dividend and basis metadata contracts.** Dividend dates are ex dates without payment dates or schedule/cash currency consistency checks. Basis curves describe a continuous foreign-minus-domestic zero spread but carry no enforced leg/currency/unit tag and have no generic bump path. Adopt caller contracts and supported uses, including yield/stock dividends, currency consistency, event-date semantics and same-date event ordering. Agree basis caller units, default tails and quote-recalibrated versus direct-level risk. Records: [09](core-market/basis-spreads.md), [13](core-market/dividend-events.md).

## Arrow interchange

[Scope inventory](arrow-interchange/README.md).

- **Observed — Direct Arrow and envelope JSON have different nonfinite semantics.** Direct export retains `Some(NaN/±∞)` as present floating values. Core envelope variants derive ordinary serde, whose pinned JSON serializer emits nonfinite floats as null: a nullable round trip loses present-versus-missing identity, while a nonnullable float vector cannot restore that null as f64. This is static serializer/type evidence, not an executed round trip. Reconcile both transport contracts with ADR 0009 and qualify nullable/nonnullable paths. Records: [001](arrow-interchange/01-typed-values-and-null-semantics.md).

- **Observed — Raw envelopes bypass checked unique-name admission.** `TableEnvelope::new` rejects duplicate names, but public fields and derived deserialization bypass it. Export relies on Arrow row-count/type/nullability checks, which do not enforce unique names. Equal-length raw duplicate-name tables therefore follow an accepting static path, unlike checked construction. The API specifies a validated input; choose the invariant owner and qualify raw duplicate-name and shape-error paths. Records: [003](arrow-interchange/03-envelope-boundary-and-batch-assembly.md).

- **Observed — Large UTF-8 columns can panic before mapped validation errors.** Both string variants use StringArray with i32 offsets. Pinned Arrow constructors use `expect` when aggregate present bytes exceed the offset range; the adapter has no preflight or chunking before this dependency panic. Even constructor-valid envelopes can reach it. Choose a checked size limit, larger canonical representation or explicit chunking policy and qualify its resource/error boundary. Distinguish the adapter's copying conversion from later shared-buffer host handoff in consumer guarantees. No multi-gigabyte reproduction was run. Records: [003](arrow-interchange/03-envelope-boundary-and-batch-assembly.md).

- **Observed — Metadata documentation describes a parser that is absent.** The crate README says malformed metadata JSON returns a validation error, but the API accepts typed `IndexMap<String, Value>` and serializes it without parsing embedded strings or validating a metadata schema. Correct that existing statement and separately specify any required semantic schema, version, provenance policy or validation. Select canonical serialization only if stable bytes are an explicit requirement; the record does not adopt it. Records: [002](arrow-interchange/02-schema-order-and-metadata.md).

- **Evidence — Payload and metadata transport guarantees need broader qualification.** The nine-variant fixture checks schema, two null counts, two roles and two JSON strings, but not all payload values, integer extrema, signed zero/nonfinite distinctions, all-present/all-null nullable cases or nested/omitted metadata. Python comparisons share ordinary finite producer values. Qualify the stated transport guarantees and host limits independently of financial model accuracy, including empty nullable columns, all declared roles, omitted/empty and nested metadata, and retention across supported consumers. Qualify contractual-Money precision at the producer boundary separately; Float64 plus currency metadata does not establish lossless monetary export. Records: [001](arrow-interchange/01-typed-values-and-null-semantics.md), [002](arrow-interchange/02-schema-order-and-metadata.md).

- **Evidence — Empty-shape and malformed-input tests cover only part of the batch contract.** The zero-column test uses a constructor-created 0×0 table. Explicit positive rows with zero columns, zero-row typed columns and raw length/count/name violations lack inspected adapter tests. Qualify these entry paths and mapped errors; the explicit row-count option alone is not runtime evidence. Records: [003](arrow-interchange/03-envelope-boundary-and-batch-assembly.md).
