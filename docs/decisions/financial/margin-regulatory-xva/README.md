## Evidence and limits

Runtime source is primary evidence of what currently computes. Tests with explicit hand formulas or independent flat-hazard/funding closed forms provide reference-shape evidence; tests that replay stored rows, recompute the same parameter formula, round-trip wire data, or assert monotonicity establish only their stated contracts. None was executed in this audit. Source-provenance comments and the central reference index identify intended literature/standards; they do not certify current applicability or reproduce those references' complete numerical requirements.

The records preserve material behavior and scope limits, including duplicate-wire
handling, curvature correlations, maturity-factor summaries, capped EAD,
effective-EPE diagnostics, DVA sign and opening-IM treatment. Observed behavior
does not establish financial adoption or regulatory qualification.

The [regulatory-margin/XVA follow-ups](../FOLLOW_UPS.md#margin-regulatory-capital-and-xva)
own implementation discrepancies, guidance reconciliation, pending adoption
questions and missing validation. Records retain algorithms, scope, evidence
and lasting limitations, with links to that register. There is no uninspected
production-file deferral in this scope.
