## Evidence and decision boundaries

- Owning implementation: [complete `lib.rs`](../../../../finstack-quant/arrow-interchange/src/lib.rs), with contract documentation in the [crate README](../../../../finstack-quant/arrow-interchange/README.md).
- Construction and wire boundary: [core table types](../../../../finstack-quant/core/src/table.rs). [Cargo.toml](../../../../Cargo.toml) selects Arrow 57 and serde_json with `float_roundtrip`; [Cargo.lock](../../../../Cargo.lock) pins `arrow-array` / `arrow-schema` 57.3.1 and serde_json 1.0.151. Pinned local dependency implementations provide source evidence, not independent conformance testing.
- Producer semantics remain with their owners: [statements export](../../../../finstack-quant/statements/src/evaluator/export.rs) supplies text period IDs and floating amounts; [portfolio export](../../../../finstack-quant/portfolio/src/dataframe.rs) converts `Money` through `amount()` before this adapter.
- Host handoff: [Python wrapper](../../../../finstack-quant-py/src/bindings/core/table.rs), [host behavior tests](../../../../finstack-quant-py/tests/test_arrow_interchange.py), and [producer shape tests](../../../../finstack-quant-py/tests/test_to_arrow_producers.py). These do not establish every possible host conversion's fidelity.
- [ADR 0009](../conventions/0009-missing-and-invalid-data.md) requires operation-specific missing/invalid distinctions; it does not impose global NaN rejection. [ADR 0020](../conventions/0020-numerical-representation-and-rounding.md) governs monetary precision boundaries; plain Float64 export does not certify contractual Decimal fidelity. Open issues are consolidated in the [Arrow-interchange follow-ups](../FOLLOW_UPS.md#arrow-interchange).
