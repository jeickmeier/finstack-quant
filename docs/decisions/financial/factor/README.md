## Scope and boundaries

This scope covers all `finstack-quant/factor/src/**/*.rs`: multi-asset factor contracts and matching, covariance/sensitivity storage, factor and position risk allocation, historical/stress/budget reporting, credit hierarchy calibration, snapshot decomposition, horizon scaling, and artifact/schema boundaries. Production code following the early test-only helper in `matching/matchers.rs` is included. Dedicated test bodies are evidence rather than production algorithms; selected hand calculations and boundary cases were inspected and the remaining test families located.

Portfolio dependency extraction, market bumping, repricing, FX translation, issuer residual construction and factor stress application belong to the portfolio scopes. The delegated analytics beta and core PSD/repair/shrinkage/normal kernels are cross-boundary evidence, not reimplemented here. Factor outputs do not automatically establish common currency, factor coordinates, covariance horizon or fully captured risk.

The public credit calibrator rejects missing panel observations. Private sparse/overlap kernels are documented without advertising a supported sparse calibration workflow. The generic credit series is caller supplied; no PCA is computed by this crate despite the `pc` terminology. Accepted [ADR 0047](../../architecture/0047-credit-factor-wire-and-validation-contract.md) settles the required typed `schema` marker and its rejection during deserialization, the closed root and explicitly open diagnostics, and current-state semantic-validation boundaries. Acceptance does not certify complete implementation; the [factor follow-ups](../FOLLOW_UPS.md#factor-models) track remaining work.
