# Portfolio construction, execution and reporting methodologies

This audit covers the portfolio execution slice: holding and book contracts, canonical valuation and selective reuse, materialization, reporting FX, cashflows and risk aggregation, primitive look-through, factor repricing, scenarios, replay, and the portfolio-to-margin bridge. Its source scope is **41 Rust files: 29 algorithm files, 11 support files and one test-only fixture file**, mapped to **17 detailed records** in [coverage.json](coverage.json). Every assigned production file was read, including private helpers, fallbacks and feature-gated paths. Embedded test modules were inspected selectively as evidence; this is not a claim that every test body was reviewed.

- **Decision status:** Draft — observed implementation; adoption of individual methodologies remains pending. Existing accepted architectural, arithmetic and validation requirements remain binding.
- **Implementation status:** Observed for the assigned source scope, with concrete discrepancies and limits recorded below.
- **Validation status:** Source and selected test evidence inspected or located; tests, builds, benchmarks and numerical reproductions were not executed.
- **Audit date:** 2026-11-05. **Source revision:** `7e82fd03ad98346727769e88dd5ac5d84b56e9fc`. Exact reviewed source hashes and ownership are in the coverage ledger.

Instrument pricing formulas remain with their product methodology owners. Portfolio attribution, optimizers and assignment-based credit-factor behavior are covered by [portfolio attribution](../portfolio-attribution/README.md); scenario transformations by [scenarios](../scenarios/README.md); factor types/statistics by [factor](../factor/README.md); and SIMM, schedule, CCP and collateral formulas by [margin](../margin-collateral-im/README.md). These boundaries do not exclude the dispatch, scaling, failure and aggregation choices made by this portfolio slice.
