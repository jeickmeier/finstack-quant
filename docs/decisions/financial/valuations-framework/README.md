# Valuations framework methodology audit

This slice covers all **128 assigned Rust files**: 126 under `finstack-quant/valuations/core/src` and both production sources of `finstack-quant/valuations/macros/src`, including runtime definitions following inline test modules and embedded convention/default data consumed by those files. The exact [coverage ledger](coverage.json) classifies **91 algorithm-bearing, 36 support and one test-only file**, each once. Twenty draft records document the observed algorithms. Support files include actual re-exports, plain result/quote containers and diagnostic plumbing; defaults, economically material validators and dispatch policies are classified as algorithms.

The current ownership ledger also includes the [registry snapshot generator](../../../../finstack-quant/valuations/src/bin/gen_registry_snapshot.rs), classified as support on 2026-11-08. This brings current coverage to **129 files**; it does not extend the original pricing-algorithm audit.

Audit date: **2026-11-05**. Source revision: `7e82fd03ad98346727769e88dd5ac5d84b56e9fc`. Decision status for the detailed algorithm records is **Draft — adoption pending**. Source and selected test evidence were inspected/located, but **no runtime tests, builds, calibration runs or external accuracy benchmarks were executed**. Formula tests, round trips and reconciliation with another production kernel are distinguished from independent evidence. This audit changes documentation, not pricing choices or source behavior.

Product engines, underlying core/cashflows/models kernels and external recalibration providers have their own records. The framework records explain their real dispatch/default/domain contracts without treating an enum name as proof that every product supports the associated method. Unresolved choices are specific to the observed behavior; none means that algorithm inspection of this slice is deferred.
