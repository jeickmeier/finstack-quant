# Features algorithm methodology inventory

**Decision status:** All 22 records, FEATURES-001 through FEATURES-022, were accepted on 2026-11-17.

**Scope:** All **11 Rust source files** in `finstack-quant/features/src` were audited at `7e82fd03ad98346727769e88dd5ac5d84b56e9fc` on 2026-11-05. There are **8 algorithm-bearing files**, **3 support files**, **22 decision records**, and **59 algorithm-level inventory rows**. [coverage.json](coverage.json) maps every assigned source exactly once with its verified SHA-256 digest.

The source audit inspected every assigned runtime file, both feature integration-test modules, and selected core dependencies, schemas, and binding callers. The decision review added independent numerical examples. Runtime reconciliation, Rust test execution for the accepted contracts, and host qualification remain open.

The scope is generic numeric panel features; it has no instrument, Money, currency, Date, calendar, frequency or price-adjustment model. Caller-supplied keys define the population and ordering. Records cover every time-series/cross-sectional/pairwise selector, grouped execution, neutralization, weight compositions and typed/JSON pipeline. Core owns delegated compensated sums, sample covariance/variance and inverse-normal calculations; nalgebra owns the SVD decomposition. This inventory records how features selects and interprets them, not a new audit of their entire crates or bindings.

[ADR 0009](../conventions/0009-missing-and-invalid-data.md) preserves distinctions among invalid, missing and unestimable data, while its concrete performance-panel rules remain scoped to analytics. [Reproducibility invariants](../../../../INVARIANTS.md#21-reproducibility-tiers) limit cross-target claims.
