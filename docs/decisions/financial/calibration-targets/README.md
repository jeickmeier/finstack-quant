# Calibration target methodology audit

- **Decision status:** ADR 0032 and all 17 CALIBRATION-TARGETS records are **Accepted**.
- **Implementation status:** Observed for all assigned source files; scope and evidence limits are described in the records; open work is tracked in the register.
- **Validation status:** Audit source and selected evidence inspected. Accepted records document independent calculation checks and pending production qualification.
- **Audit date / source revision:** 2026-11-05 / `7e82fd03ad98346727769e88dd5ac5d84b56e9fc`.

This scope covers **25 assigned Rust source files**: **21 algorithm-bearing files, 2 support/module files and 2 dedicated test files**, accounted exactly once with source hashes in [coverage.json](coverage.json). The **17 records** document quote contracts, target parameterization, residuals/weights, numerical search controls, carry/clock resolution, volatility materialization, inverse solves and replay. The **45 inventory rows** distinguish meaningful algorithms and dispatch choices rather than only product families. Runtime after the early test-only import in swaption.rs was inspected; no production code was excluded at that marker.

[Calibration framework](../calibration-framework/README.md) owns envelope/preflight, quote instrument builders, shared bootstrap/global/scalar solvers, reports, validators and recalibration. [Core market](../core-market/README.md) owns curve representation; [model analytic methods](../models-analytic/README.md) own SABR/SVI evaluation/fitting kernels. This scope records the actual target selections and transformations at those boundaries. The linked records identify same-kernel roundtrips, algebraic checks, invariants and externally attributed fixtures and document subsequent adoption evidence.
