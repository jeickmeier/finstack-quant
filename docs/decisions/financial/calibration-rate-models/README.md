## Evidence and adoption limits

The scalar fit uses two distinct objectives: fixed-κ cap fits minimize raw premium SSE, while free-κ/σ fits divide premium errors by quote vega. Final reported fit errors reconstruct quoted volatility. The piecewise path freezes earlier intervals and uses the last live fixing horizon; the LMM path matches only one ATM target under frozen weights. Model choice, numerical acceptance and economic identification remain separate questions.

Independent evidence is narrow: contractual swaption integration has an analytically tractable one-coupon comparison with independently assembled covariance; LMM has a one-forward analytical premium case. Most parameter recovery and cap/swaption consistency cases reuse production kernels. All were read, not executed. The inspected evidence does not establish broad accuracy for bounds, negative-rate/signed-coupon behavior, multi-forward approximation or market calibration stability. Existing adoption status is preserved; this catalogue does not approve new methods.
