Audit date: **2026-11-05**. Source revision: `7e82fd03ad98346727769e88dd5ac5d84b56e9fc`.

Independent arithmetic, solver and dated-return examples were checked. Runtime, host and numerical-range qualification remain pending. No Rust builds, tests or lint tasks were run for this scope.

The separate [attribution crate](../attribution/README.md) owns instrument P&L kernels and shared translation. The [factor crate](../factor/README.md) owns matching configuration, covariance and risk-decomposition kernels. [Core XIRR](../core-conventions/017-irr.md) owns root solving. Portfolio execution/valuation/sensitivity machinery is another scope. This inventory documents the caller's selection, composition and additional assumptions without claiming to re-audit those dependencies.
