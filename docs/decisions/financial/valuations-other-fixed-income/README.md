# Other fixed-income methodology inventory

This scope covers bond futures, convertibles, inflation-linked bonds, shared loan quotes/terms, term loans, revolving credit, agency MBS, TBA/dollar rolls and fixed-income index TRS. It contains **87 assigned Rust source files: 73 algorithm-bearing, 13 support and 1 test-only**, mapped exactly once in [coverage.json](coverage.json), and **16 methodology records**. Ordinary bond algorithms belong to [valuations-bonds](../valuations-bonds/README.md); shared trees, simulation processes, cashflows and valuation-framework kernels are linked from the product records.

Audit snapshot: **2026-11-05**, revision `7e82fd03ad98346727769e88dd5ac5d84b56e9fc`. Production implementations were inspected, including material defaults, validation and dispatch in `types.rs`, registry files and source appearing after inline test modules. Data/config dependencies are recorded where they select algorithms. The classification count describes source coverage, not independent validation or adoption.

Six records are **Accepted** and ten are **Draft**. The bond-futures, convertible, inflation-linked bond and shared loan quote records contain accepted decisions and independent arithmetic. The original audit inspected source and named evidence without running Rust builds, tests or external price reconciliations. Evidence rows distinguish internal formula checks, independent arithmetic and production qualification.
