# Analytics algorithm methodology inventory

**Scope:** all **21 Rust source files** in `finstack-quant/analytics/src`, audited at `7e82fd03ad98346727769e88dd5ac5d84b56e9fc` on 2026-11-05: **18 algorithm-bearing files and 3 support files**, no dedicated test-only or generated source files. [coverage.json](coverage.json) maps every assigned file once with the reviewed SHA-256 digest. There are **15 detailed Draft records** and **44 algorithm-level inventory rows**.

All assigned runtime implementations were inspected, including financial validation/defaults, private numerical kernels, serde reconstruction and code after test sections. Related core functions and selected tests were inspected or located for the evidence roles stated in each record. The core crates own general moment/day-count/linear-algebra kernels; this slice owns analytics caller selection and interpretation. There were **no runtime changes, builds, financial calculations, tests or benchmarks** in this audit. Static coverage/link checks are documentation checks, not estimator validation.

Existing accepted decisions remain authoritative. The observed code still conflicts with the accepted ACT/365F dated-CAGR default and prior directions for actual initial valuation dates, explicit invalid-Cornish–Fisher errors, strictly positive up-capture, cash-adjusted Martin and modified Burke over all episodes. Those are reconciliation requirements, not new optional methodology choices. The records distinguish these from unresolved numerical/reference qualification and new static wire-contract concerns.
