# Models remediation plan, rebased on the accepted decision records

**Status:** proposed, not started. Written 2026-11-16 against `305337db52`. Nothing here has been built or run.

**Replaces:** the 7-slice "finstack-quant-models & Bindings Blocker/Major Remediation" plan for the
23 findings of the models stepwise quant audit. That plan patched the current API shapes; this one
implements what the accepted records under `docs/decisions/financial/` prescribe for the same code.

**How it was produced:** each slice was drafted from a full read of the "Accepted decision" section
of every governing record plus the source the finding touches, read from a working tree with
unrelated uncommitted changes. Re-checked by hand afterwards:

- the "not reproducible", "already fixed" and "does not exist" entries in the table below (#3, #8,
  #11 IRR, #13 COS, #16 FX, #18 Sobol, #23) against source;

- that CORE-NUMERICS-20 is not implemented in `core/src/math/time_grid.rs`.

Every other decision citation is as drafted. Treat a cited decision number as a pointer to read,
not as a substitute for the record.

## Scope rule

For each finding, a slice implements:

1. the record decisions that govern the finding's code path, and
2. any decision that deletes, renames or re-signatures an API the fix touches, so nothing built in
   the slice is removed later (`AGENTS.md`: no stopgaps, no compatibility layers).

Every other decision in the record is listed under **Deferred** in the slice with the reason it is
separable. Finding numbers (#1 to #23) are the audit's.

#### #13b Heston characteristic function false overflow (Major)

- **Defect (verified in source, location differs from audit):** There is no `char_func`/`heston_integrand` and no `closed_form/heston.rs` file. The function is `heston_pj_characteristic_function` in `finstack-quant/models/src/volatility/heston.rs`. With `b_1 = kappa − rho·sigma_v < 0` and phi near 0, `bm + d` tends to 0, so the `HESTON_G_DENOM_EPS = 1e-8` relative guard returns `(0, HestonCfStatus::Overflow)`. `closed_form/heston/strip_pricer.rs` sets `HESTON_STRIP_MAX_CORRUPT_FRACTION = 0.0`, so one such node fails that grid; `heston_call_prices_fourier` in `closed_form/heston/fourier_prices.rs` discards the error, retries up to six wider/finer grids and then reports non-convergence. The audit's fix (re-orient `Re(d)`) contradicts the record, which keeps the positive-real-part root.
- **Record remedy:**
  1. Replace the function with a crate-private typed `heston_log_cf` returning `Result<Complex64>`: the affine logarithm L, finite, with nonpositive real part. Delete `HestonCfStatus`, the zero sentinels and `HESTON_EXPONENT_REAL_LIMIT`. Invalid inputs are validation errors; unresolved range/phase/bound are computation errors. — MODELS-ANALYTIC-08 d17
  2. Take a crate-private cash/share contour selector and a finite real u of either sign; remove the `j: u8` selector and its implicit P2 default. — MODELS-ANALYTIC-08 d3
  3. Evaluate in the carry-normalised coordinate X_T=log(S_T/F); no spot, strike, carry or discount enters the evaluator. — MODELS-ANALYTIC-08 d2
  4. u=0 or T=0 returns L=0 on either contour after admission. — MODELS-ANALYTIC-08 d8
  5. Riccati constants b_1=kappa−rho·sigma_v, b_2=kappa, a_1=+1/2, a_2=−1/2, Q=−u²+2i·a_j·u, B=b_j−i·rho·sigma_v·u; the same kappa·theta on both contours for b_1<=0. — MODELS-ANALYTIC-08 d11
  6. d=sqrt(B²−sigma_v²·Q) with positive real part, computed without cancelling the positive part. — MODELS-ANALYTIC-08 d12
  7. Decaying form without g: J=−expm1(−dT)/d, Z=1+(B−d)J/2 (or exp(−dT)+(B+d)J/2), D(T)=QJ/(2Z), A_c(T)=kappa·theta[(B−d)T−2·Log(Z)]/sigma_v²; rationalise a cancelling B∓d through their product sigma_v²·Q; delete `HESTON_G_DENOM_EPS`. — MODELS-ANALYTIC-08 d13
  8. Principal Log of the full ratio Z; unresolved branch geometry is a computation error. — MODELS-ANALYTIC-08 d14
  9. Complex expm1 and log1p remainders for short time and small sigma_v; A_c numerator as (B−d)(T−J)+2[W−Log(1+W)] with W=(B−d)J/2; no substitution of the deterministic formula. — MODELS-ANALYTIC-08 d15
  10. Callers: `strip_pricer.rs` (production strip and the test-only `heston_pj_with_diagnostics`/`heston_pj_on_grid`) use the checked log, restore the phase with log(F/K) at the established sign, and propagate errors instead of counting corrupted nodes; `HestonStripPricer::new` stops swallowing failures into `None`, and the six-grid loop in `heston_call_prices_fourier` returns a hard log-CF error immediately instead of treating it as an unresolved grid (its retry on finite unresolved tail/mesh diagnostics stays). — MODELS-ANALYTIC-08 d18, d19; MODELS-ANALYTIC-09 d21
- **Differs from the old plan:** The formula is the same (the old plan's J/Z decaying form is 08 d13). The API is not: the record removes the `(Complex64, HestonCfStatus)` return, the integer selector and the spot/carry arguments, so the strip caller changes too.
